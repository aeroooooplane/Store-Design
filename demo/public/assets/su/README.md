# 本地真实 SU 浏览器资产

此目录只保存由正式 v2 DAE 派生的 GLB，原始资料不改。资产子目录不推送 Git；使用相同本地源运行转换脚本复现：

```powershell
cd demo
node scripts/convert-su-assets.mjs asset-408124
```

脚本拒绝覆盖已有输出，并检查源纹理加载、米制/Y 向上转换、底部中心原点、GLB 重载尺寸（1 mm 容差）。conversion.json 记录来源及 SHA256；尺寸通过不等于材质视觉验收，也不确认 SI 或正面方向。

首张 asset-408124 尺寸约 1.0 × 1.8 × 1.326885 m（宽 × 深 × 总高，包含模型中已有物件）。GLB 约 32.5 MB，尚需视觉检查和资源预算处理；不得直接把它当作轻量化完成或网页已接入。
