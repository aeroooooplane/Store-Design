# 工作台使用与开发

更新：2026-10-04。当前范围是平面调整、三维查看与多角度概念效果。项目总览见 [根目录](../README.md)，代码职责见 [实际架构](../docs/architecture.md)。

## 启动

在本目录执行。首次安装用 `npm.cmd ci`；已有依赖时直接构建：

```powershell
npm.cmd run build
npm.cmd run preview -- --host 127.0.0.1 --port 64071 --strictPort
```

工作台 <http://127.0.0.1:64071/>，模型库 <http://127.0.0.1:64071/model-library/>。开发调试可用 `npm.cmd run dev -- --host 127.0.0.1 --port 5179 --strictPort`。

日常固定使用64071。浏览器保存按网址来源隔离，开发端口和预览端口不共享项目；切换前导出JSON，再按需导入。端口占用时先核对已有服务，不直接结束不明进程。

## 操作流程

1. 输入长宽、层高和铺型，或使用面积比例／标准桌长比例估算。范围：长宽4–30m，层高2.4–6m；面积不能还原真实户型。
2. 比较四个候选平面，点击进入编辑。拖动、输入位置、旋转90°、增删道具；重叠、越界或超过层高时先修正。动线与消防仍需人工核对。
3. 保存快照或确认白模。删除可撤销最近20次；保存、换方案或刷新会清除此临时撤销记录。
4. 等待真实网格载入，旋转检查白模，选择 SI1.0／SI2.0 参考环境生成八视角。两套环境是概念参考，具体门店材质仍须按标准核对。
5. 下载平面或效果包，并导出项目JSON。历史节点可以恢复，“复制当前布局继续编辑”会创建独立分支。

| 输出 | 用途和边界 |
|---|---|
| 平面SVG | 尺寸、编号和占地；按原尺寸打印1:50，非施工图 |
| 平面PNG | 分享预览；最长边4096、最多800万像素，不保证打印比例 |
| 八视角ZIP | 同一分支的八张960×640 PNG、布局、平面SVG、机位及哈希清单 |
| 项目JSON | 节点、分支和草稿；不含GLB、SU或渲染图片 |

## 保存、恢复和迁移

- 布局与草稿使用浏览器 localStorage，键为 `insta-studio-v2`；渲染图片仅在内存，刷新需重渲染。
- 导入限制为5MB、500节点、每方案200道具；校验后合并为独立分支。200是数据上限，不是复杂模型性能承诺。
- 同时打开多个窗口时，较旧窗口会阻止覆盖。先导出该窗口JSON，再刷新读取新项目。
- 存储失败时导出备份；损坏记录进入恢复保护，可下载原始数据或隔离备份后新建。
- 清除站点数据会清除浏览器项目及本地隔离副本。换电脑需带上JSON和相应本机素材；Git代码同步不是项目或资产备份。

## 模型库与案例

`/model-library/`提供90件已命名SU的预览和下载：38件软装（SI1.0／SI2.0／待确认）、19件信息化、33件展陈。45件已有逐模型纯净平面图例，名称在图外，已核对桌型的底座／腿位用虚线表示；原25张裁片及出处保留。完整指引在模型库“使用指引”。

工作台中的“90项资产目录”是源资产文字索引；当前摆放清单记录22项GLB，但本机缺少这些实体；90件SU及271张预览/图例已补齐，可浏览和下载。现有参数化布局不会被自动替换成SU。

“查看五店案例证据”提供15条平面、18张效果参考。主动载入时才通过本地服务读取并校验来源。它们不是完整几何标注，也不会自动生成实际户型。

原始标准、SU、GLB、案例PDF保存在项目本机目录。只复制`dist`到静态托管，不会提供这些文件服务；网页启动无需SketchUp或训练环境。

## 维护入口

- 前端：`src/app`协调流程，`src/components`负责平面和三维界面，其余领域模块管理几何、导入与保存。
- 样式：`src/styles/tokens.css`为共同主题，`workbench.css`和`model-library.css`分别负责两处布局。
- 本机服务：`server/local-evidence.mjs`和`server/local-model-library.mjs`，由`vite.config.js`挂接。
- 离线工具：`scripts`生成轻量案例／资产索引，`../tools/sketchup`生成模型目录和图例。

修改目录样式或模型清单后，从项目根目录运行 `python tools/sketchup/build_model_catalogue.py`，再构建网页。不要手改生成HTML再遗漏生成器。

## 验证

```powershell
npm.cmd run build
npx.cmd playwright test --workers=1
# 需要64071预览服务正在运行
node scripts/check-model-library.mjs
```

完整默认测试会按配置跳过本机大文件和性能专项。生产专项：设置 `$env:PRODUCTION_QA='1'` 后运行 `npx.cmd playwright test --config playwright.preview.config.js --workers=1`，结束后删除该环境变量；需要本机GLB和案例证据。它使用独立测试浏览器，不改日常项目。

真实资产专项由 `REAL_ASSET_QA=1` 开启，性能专项由 `ASSET_PERF_QA=1` 开启；测试入口分别为 `tests/asset-viewer.spec.js` 与 `tests/asset-performance.spec.js`。共享网格加载与资源释放有验证，不能由短时测试推断长期GPU性能。

截图和报告在 `output/web-qa`、`资源库/05_店铺形象设计标准/历史阅读记录`；本轮整理验收在 `output/maintenance`。已知构建体积提示与未来优化见整理记录。
