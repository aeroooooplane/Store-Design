# 三维边界墙：通高与半透明

所有实际边界墙在三维白模、材质视图和新生成的渲染图中按空间层高展示，统一灰色。仅改变展示网格与材质，不改Space高度、边界、入口、开边、排布、碰撞或平面/交付尺寸。原先没有实际边界墙的中岛店不新增围墙。

材质参数：颜色`#8f8f8f`，不透明度`opacity=0.24`（透明度76%），`transparent=true`、`depthWrite=false`、`FrontSide`，粗糙度0.9、金属度0。闭合墙盒仅绘制朝向相机的面，避免同一墙前后面重复叠色；透明物体由Three.js按距离排序。边界墙`renderOrder=1`，位于不透明物件之后；选择标记沿用原顺序。透明边界墙不投射原实心墙阴影，矮柱、矮柜和空心隔板仍保留原高度、实心材质及阴影规则。共用边界材质在场景释放时销毁。

几何仍沿用wallSegments的分段结果，保留入口与开边，只把边界展示网格拉至space.height，不改共享墙段契约或平面几何；未来新开洞仍应由原分段/开洞逻辑提供。灰色透明只作用于boundaryWall标记，不按所有wall表面批量替换，避免误处理障碍物与隔板。

本地15项直接相关测试及静态检查通过。浏览器以同一8×6×3.2 m空间和相机生成前/后五向白模、五向材质图；5个边界段均高3.2 m且opacity=0.24，0.9 m隔板与1.2 m矮柱保持原样。四面灯箱和旧LOGO朝向正确，透过墙选择灯箱、三维角点独立拖动通过，脚本错误0。

证据位于本worktree忽略目录output/web-qa/boundary/：before-after.png、after/的10张视图与result.json、tests.log、format.log。旧图在灯箱worktree的output/web-qa/lightbox/views/；新图使用5192前端和本任务隔离3021 API，未操作主5173/3001服务。既有归档图片和PDF不会自动改写；新渲染使用此展示规则。无新模型、图片资源或LFS增量。
