# 从图纸到可编辑空间：首个完整样例

2026-11-12。本轮按用户要求改为产品闭环验证，不再追加训练轮次。复用独立试点 PDF-231 武汉银泰创意城的原图与代理描点，校正入口后交付工作台原生项目：导入、修改边长/层高、保存、刷新、三维预览、导出及重新导入已实测通过。

这是一家**代理辅助校正的空间样例**，不是新增的全自动识图功能，也不表示原 24 家试点或整店家具制作完成。

## 交付与操作

外置目录：`<外置产物根目录>/recognition-usable-20261112-v2/`。

- `完整样例.store-design.json`：工作台项目列表直接导入，包含原图空间和尺寸演示空间两个节点。
- `原图空间.store-design.json`：仅包含校正后的原图空间。
- `审核页.html`：黑白黄本地审核页，下载文件、对照截图、查看来源，集中一项隔墙高度确认；记住答案、撤销、导出并返回顶部。不读写旧 48 家审核。
- `原图.png`、`原图第12页.png`、`原图第19页.png`、`尺寸依据.json`、`来源与限制.json`：原图、尺寸及校正依据。
- `01-导入平面.png` 至 `04-重新导入三维.png`、`验证结果.json`、`审核页验证.json`：真实 Chrome 页面证据。
- `云端方案.md`：候选服务商、拟发送内容及启用流程。未发图、未调用。
- `replay/`、`检查日志/`、`文件指纹.json`：重放脚本、测试日志和逐文件 SHA。

在工作台项目列表点“导入项目”，选完整样例。打开项目后选择任一空间节点；“修改空间”调整尺寸，“保存空间”创建新节点，再点“三维”。道具使用“手动排布”，没有自动摆放。

首版 v1 的链路虽跑通，但补查原图发现入口尺寸偏差，故保留 v1 供追溯，**交付 v2**。这次没有把旧错值包装成最终样例。

## 待确认与边界

QUS-01：休息室两段轻钢龙骨隔墙是否按4米通高展示？原图第10页有室内高度4000，第12页未明确这两段墙的顶标高。当前 `height:null` 只用于随空间层高预览，不标成人工审核通过。选项：按4米展示 / 另填高度 / 暂不确定。推荐先保留通高预览，待答复后建立新版本，不改写原审核。

- 本样例不包含家具、灯箱贴面、门头、内部门洞、材质灯光或施工节点。灯箱/广告机后续遵守贴墙面规则，不挖槽、不做内嵌实体块。
- 外轮廓修改后隔墙保持原位，需要设计者调整；现有多边形障碍在空间表单内只能原样保留或删除。
- 原生导出没有完整携带来源/审核扩展字段，须把侧车资料一并归档，不宣称所有旧档案无损导入。
- 该独立试点店此前参与过训练资料制作，不用于证明未见门店的泛化；本轮只验证产品闭环。48家继续开发复评，45家验收隔离。
- 云端候选为阿里云百炼（DashScope）；拟发送所选主平面及必要局部、尺寸文字、匿名编号和字段规则。身份信息先裁去，但布局仍会外发。模型、地域、保存策略、费用和具体待发图片启用前核实展示。本轮仅方案，不启用。
