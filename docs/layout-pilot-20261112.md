# 24家布局数据与工作台试点（2026-11-12）

## 路线调整

按用户最新授权暂停图纸识别迭代，保留已有代码、模型和审核结果。主线改为已审核标注的数据整理、工作台原生导入和自动排布。当前功能复用已有本机规则排布器，没有训练新模型、调用云端或修改通用排布/UI业务代码。

## 本轮范围

从48家已审核开发集冻结24家：10家边厅、11家中岛、3家专区，覆盖SI1.0/SI2.0、直角/异形、多入口及国内外门店。24家仍属开发集，不转为训练集；45家只读取既有身份索引排重，不读图像、标注或评分。此前独立24家试点保留，本次不以其未完成状态要求用户重新标注。

本轮复用最新整店审核包v16的388项标注，原字节副本、审核人、时间、答案和全部像素坐标保留。按原量尺变换到米制，固定条件与原设计结果分别记录。只把具有明确高度和矩形外框的128件家具映射为原生占位参考；其他原对象仍完整留在二维审核和JSON，不能称388件均已三维化。

## 输入与输出

- 输入空间：原允许使用范围、柱/原墙/设备/后场，以及暂保留的现状隔断包板投影。跨边界障碍取店内相交部分；原对象和租赁边界不变。柱/原墙扣面积，其余后加或暂留设计仅避让。
- 入口：边厅保留并记录必要的边界投影，超过20毫米列审核；中岛按开放场地试排，原通行线只作结果参照。尚未完成从排布结果自动定义通行网络。
- 原图参考：保留可表达的已知高度家具位置，不直接当作自动方案。
- 自动候选：只向已有 `/layouts/generate` 传空间、铺型和SI；未把原图家具位置或数量传入。沿用现有标准模型与三种数量策略。
- 高度：3米只沿用H3预览默认值，非原图实测；12段已有明确高度的避让体按原值生成，未知家具高度留空。灯箱/广告机保持二维待安装依据，不做嵌墙实体。

## 当前结果

24家生成24份原生项目。72组候选中69组非空且通过现有几何校验，按同店道具、位置与朝向去除策略重复后共55种不同布局。PDF-245泰国Mega Bangna的三组均为空，原样保留，不换样本或擅自缩小模型。不能把69组称为69套独立设计，更不能等同业务验收通过。

20组候选放宽了现有通道/间距指导值，逐项保留原值和实际值；只有12家至少一组含收银台。现有排布不涵盖开箱桌、坐凳、屏幕、灯箱、软装装饰及硬装重设计，因此本轮全店自动完成率未宣称。参考道具数量不是本轮硬性需求，需下一步补经营需求后检查缺配。

24家三策略接口合计约4.22秒（本机本轮墙钟，含本地请求，非生产SLA）；资料适配与浏览器验证时间不计入此数。没有声称节省人工设计工时，本轮并未进行24家逐店人工优化计时。

首次转换PDF-050、PDF-140、PDF-261的跨界障碍出现三角分片短边，导致空间校验失败；通过不增加面积的相邻凸片合并修复，名单和原标注保持不变。首轮结果与限流失败另存，未丢弃。再次验证沿用相同规则排布器。
