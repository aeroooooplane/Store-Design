# 渲染背景编辑前端验收

## 实现

- 渲染页直接添加/编辑背景；三维及渲染图主视图区可拖入 PNG/JPEG。空编辑临时隐藏半透明墙，已有图片尊重保存的墙开关。
- 每视角一张图片，锁定比例，移动/缩放/旋转手柄及精确输入，支持归位、替换、移除。
- 照片坐标闭合遮罩、顶点编辑与删除；照片坐标两点辅助线、显隐与删除。复用模型模块变换矩阵及共享多边形校验。
- 每视角独立撤销/重做，一次拖动一步；输入框保留原生文字撤销。替换图片清空遮罩和辅助线，撤销可整体恢复。
- 每视角同步上传锁、串行保存和版本检查；旧响应仅确认对应快照。保存失败保留本地编辑，可重试或明确放弃重载。渲染/交付等待保存，失败和过期图阻止交付。
- 独立样式使用品牌变量，预览固定 3:2，与 1800×1200 渲染坐标一致；手柄保持屏幕尺寸。

## 边界

- 控制点、辅助线和编辑中的半透明遮罩提示仅用于编辑；正式图只包含照片、模型及恢复原照片的遮罩。
- 上传单图不超过 16 MiB；最多 32 个遮罩、每面 3–100 点、100 条辅助线，拒绝自交面。
- 撤销历史驻留当前前端编辑会话；重新载入页面读取已保存的背景，不恢复撤销栈。失败时需重试或明确放弃；页面关闭/刷新有未保存提示。
- 本轮不改受保护平面类名和导出 CSS，不改识别与历史树交互。
