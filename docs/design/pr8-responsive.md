沿用 docs/design-system.md 与 pr1–pr7：墨黑 #111、品牌黄 #FFD200、白 #FFF、暖灰 #F4F3EF、浅灰 #F8F7F3；字体继续使用 Inter 和系统中文字体。主内容左对齐，面板统一 12px 内边距和间距，阶段按钮至少 36px 高。

布局：导航 / 返回栏 / 项目信息 / [历史与模型 | 画布 | 阶段操作]。桌面三栏共享剩余高度；小屏自然单列。首页采用标题 / 新建 / 搜索 / 可滚动项目表 / 分页。

## 根因与修改

原 page-workbench 在导航之外又设置 100vh 最小高度，左右栏重复估算可用高度，中央画布随宽度扩展，造成溢出和底边不齐。1180px 断点下历史区固定 460px；首页新建表单固定五列在手机宽度溢出，长表把分页推出首屏。

桌面使用动态视口高度与 flex 剩余空间，长列表局部滚动；画布保持比例适配可用高度。小屏及低高度窗口恢复自然文档流，历史区按视口高度限制。首页表格滚动容器支持键盘焦点，表头固定，分页和新建操作保持可见；窄屏表单改两列，表格可横向滚动。

仅修改 app.css、workbench.css 布局规则及 ProjectListPage.tsx 的外框/表格容器。既有平面绘图样式、保护类名、paint-order 与 plan-export 均未修改。
