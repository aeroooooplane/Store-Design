# 轮廓与入口审核页 v2

旧页面只能标一条直线入口，无法表达中岛店多侧开放、折线或圆弧入口；误点后只能删除末点。v2 增加多条入口路径、完整撤销/重做和取消本次修改，打开图纸默认只查看；审核人自动记住，确认保存后回到清单，详细依据默认折叠。

## 数据与兼容

- `schemaVersion: 2` 使用 `entrances: [{kind: 'polyline' | 'arc', points: [[x,y], ...]}]`。直线/折线至少两点；圆弧按起点、弧上点、终点三点记录。不强制唯一主入口。任意曲线可用沿轮廓的密集折线表示；三点圆弧不代表任意样条。
- 所有坐标为原图像素。圆弧保留控制点，按不超过 4 px 的弧长步长采样验证；入口全路径须在轮廓 12 px 容差内，防止只凭端点合法而穿过店内。轮廓本身仍为折线描点。
- v1 `entrance` 自动迁移成一条路径，原坐标、审核人、时间、备注及有效审核状态保持。`entranceReviewVersion: 1` 表示旧版单入口审核；在 v2 确认后才成为 `2`，不能将旧记录推定为全部开放侧已审核。
- v2 不输出有歧义的旧单入口字段。旧版消费者必须显式支持多路径才能读取，不能静默只取第一条。原 #156 的入口侧评分不因本 PR 自动改变；重新评估前需更新评分协议并保留原版结果。
- 新缓存键为旧键后加 `:v2`；旧记录只读迁移并保留备份。显式提供的用户审核包优先于旧版缓存，v2 后续修改优先于初始审核包。导入先完整校验身份、指纹、页码、重复门店与数据类型，再保存导入前备份及新缓存。
- 撤销/重做保留每店最近 100 步，包含坐标、文本、状态和审核时间，当前页面会话内有效。文本框内保留浏览器原生撤销；画布快捷键为 Ctrl+Z、Ctrl+Y / Ctrl+Shift+Z。取消本次修改恢复打开该店时的记录。确认按钮仅在校验和本机保存成功后返回清单。

## 构建与校验

```powershell
node tools/recognition/build-review-page.mjs --dataset '<已有审核包>/candidates.json' --reviewed '<用户导出的审核.json>' --out '<全新目录>'
node tools/recognition/check-review-template.mjs
```

输出包括独立的 `审核.html`、原图和缩略图、原始用户审核包、`审核-v2.json`、`迁移核验.json`。输出必须是新目录且位于旧资料包之外。构建前检查每张原图 SHA-256、用户包身份和数据完整性；不运行识别引擎，不读验收标注，不发送外部服务。

## 本轮接收结果

2026-11-04 用户交付的审核包包含 48 家已确认记录，13 家相对代理草稿有标注内容变化。接收包 SHA-256 为 `991f3d2dc35e475e623a4759b38f0cdc1e523ef9272087125da587ca6cbc96ba`。原始文件已独立备份；逐字段迁移核验通过，48 张来源图指纹一致，48 家新版校验通过。用户数据及图纸只存本机外置包，不进 Git。

用户完成的是轮廓、量尺及旧版入口审核。家具、柱位、型号、数量、安装高度和整店验收没有被此次确认覆盖。后续整店标注复用本轮空间结果，逐项补齐位置、尺寸、朝向、型号与数量，再单独审核；45 家金标准仍只用于验收。

## 验证范围

定向测试覆盖多入口、跨转角折线、圆弧、穿过内部的非法入口、v1/v2 往返、指纹和重复门店拒绝、撤销/重做、取消恢复、审核人记忆及确认返回。独立临时浏览器使用合成图纸验证真实快捷键、刷新持久化、下载和导入，未访问用户浏览器或旧审核页。完整仓库检查及 CI 状态以本 PR 最终记录为准。
