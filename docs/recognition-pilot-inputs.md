# 图纸试点：独立输入制作

2026-11-03 用户将图纸模块改由 Codex 独立负责。源资料执行与校正执行分开核对，用户继续负责歧义裁决和抽审。

`tools/store-archive/pilot_prepare.py` 只读既有档案、来源索引及页面特征，不读取验收平面标注。先用原资料分层、固定哈希排序冻结 24 家，再提取首 6 家。首批优先有不超过 120 平方米面积依据的来源，以控制首次人工核对工作量；不根据识别表现换店。排重包含编号、PDF 哈希、名称别名和同店关系；商场关系尚待复核，不能直接作为训练集。

输入参数为 `--repo`、`--resources`、`--development`、`--features`。`--profile` 只打印选样；加 `--out` 冻结名单及身份索引；加 `--bundle --manifest <已冻结名单> --out <新目录>` 提取首六资料。使用档案工具已有的 PyMuPDF 版本，不新增项目依赖。所有输出必须是资源库和全部 worktree 之外的新目录，不覆盖失败残留。

名单冻结后用 `tools/recognition/pilot-check.mjs` 复核。它核验声明及源哈希；本提取脚本另核验 PDF 页数。原页 PDF、预览、原文字/矢量及 BOM 证据均保留，逐文件哈希可追溯。初次提取的尺寸列表留空且明确 blocked，不能把提页记为完整样本。量尺端点及独立尺寸必须继续对原图核对，再按首六工作流生成校正平面和审核产物。

本次缺层：原档案 11 家专区中，5 家属于验收集、3 家属于开发集，另外 3 家未选主平面。独立且已有主平面的候选中没有专区，保留缺口，不挪用既有集合。

首批原图核对注意：NEW-074 为弧形中岛，弧长不能当端点直线长度定标；PDF-356 同页包含交底版和最终版，应使用右侧最终版并保留整页证据；PDF-081 要区分员工休息室与邻铺；PDF-231 的开放边不应擅补实体墙。这些是需在校正中核查的来源事实，不代表样本已验收。

可复现输入目录和实际状态由协作看板记录；共享资源、45 家验收及 48 家开发集的原标注保持只读。当前工具不完成 OCR、边界/道具识别或人工校正，也不授予训练准入。
