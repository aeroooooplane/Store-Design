# 当前项目范围

更新：2026-10-04。早期需求保留在 [历史草案](archive/20261004-before-refresh/project-brief.md)。

目标是辅助门店空间方案设计：输入空间参数、比较平面、人工调整、核对三维，再输出多角度概念效果与可继续编辑的项目备份。

当前输入支持矩形长宽／面积比例、层高、铺型，以及标准桌长比例估算。已有四方案、道具编辑、真实资产接入、分支、备份恢复、白模、八视角输出和可追溯模型目录。

界面采用瑞士风格的极简黑白排版。门店 SI1.0／SI2.0 依据各自标准、结构和陈列判断，不等同于网页黑白主题，也不能简单归纳为“灰色／黑色”。

原始图纸、模型和标准保留本机。当前交付为 SVG／PNG 平面、概念效果 ZIP、项目 JSON；自动识别完整真实户型、施工图、完整 PDF 交付包和云同步仍未实现。

尺寸、布局、模型、渲染必须可相互核对。未知内容明确保留待确认，标准和模型的识别记录可以追溯。
