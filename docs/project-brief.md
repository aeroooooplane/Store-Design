# 项目需求说明

## 1. 项目目标

建立一个以 AI 为主要执行者、用户为设计干预者的影石门店空间设计网页。系统需要从门店尺寸和基础约束出发，完成平面布局、软装布置、标准图纸、三维白膜、效果图和交付文件的连续生成。

## 2. 用户输入

- 门店长、宽、层高
- 门的位置、窗户、柱子和特殊结构
- 门店类型和设计要求
- 可选的手绘平面图或 CAD 文件
- 期望的门店风格

## 3. 核心功能

### 平面方案生成

系统根据空间尺寸、功能区域、动线规则和影石门店风格，一次生成 4 个候选平面方案。每个方案包含空间分区、家具摆位、动线和初步软装清单。

### 网页端调整

用户可以拖拽、旋转、复制、删除和替换软装，查看元素尺寸和编号，并实时看到通道、碰撞和区域约束提示。

### 标准平面图

用户确认后，系统将自由调整结果整理为标准平面图，包含尺寸标注、家具编号、区域名称、图例、比例和版本信息。

### 风格分支

标准平面图完成后显示三个选择：

1. 生成 SI1.0，灰色调，默认选项。
2. 生成 SI2.0，黑色调。
3. 同时生成 SI1.0 和 SI2.0。

空间几何、软装摆位和基础白膜可以复用；材质、灯光、标识和最终渲染按风格分支处理。

### 白膜和效果图

根据确认后的平面图和软装模型生成白膜，并从固定的 8 个标准机位渲染效果图。固定机位用于保证不同方案之间可以比较。

### 交付 PDF

PDF 包含封面、项目资料、最终平面图、软装物料清单、白膜预览图、效果图和版本确认信息。

## 4. 设计原则

- AI 负责提出方案和组合，规则引擎负责尺寸、碰撞和可施工性。
- 每个节点保存完整快照，保证可以回退和重新分支。
- 未被用户选择的风格不提前渲染，避免浪费算力。
- 平面几何与风格表现分离，便于复用和扩展。
