# S03双机位渲染对比实验

后续更新：已完成 [v2 道具结构深化](furniture-geometry-v2.md)，[对照页](../素材库/05_render_benchmark/s03-v2/index.html)。下述 v1 输入与 AI 结果保持冻结，不代表当前 Demo 的道具几何。

输入：上海星光门店现有复现草案，`demo/src/sample.js`。不是完整的图纸真值，层高、柜深等假设见原source说明。本实验测试给定3D场景经过AI增强后是否保持结构，不用同店参考图来声称布局泛化。

场景冻结在 `素材库/05_render_benchmark/s03-v1/layout.json`，物件8个：中央产品体验桌2、后侧配件柜2、左侧收银1、左侧开箱桌1、结构占位2。范围还包括后墙、右侧剖切矮墙及地面。视角取现有三维场景的0、2号相机；白膜2图，SI1.0/2.0程序材质基准共4图。布局JSON哈希和相机参数写入manifest。

AI增强使用内置imagegen：第一张输入始终为对应机位的白膜，第二张为风格参考。SI1.0参考S03原PDF效果图；SI2.0参考南宁万象城效果图，其版本沿用总表。只迁移材料与光照，不复制参考图布局。禁止增加道具、改变桌腿、改变墙/柱尺寸或机位。本轮不添加产品和标识，以免装饰细节干扰几何测试；品牌文字效果不在本轮验证范围。

## 检查与停止条件

- 可见主物件的数量、相对位置、遮挡关系是否保持；被遮挡对象不猜测通过。
- 桌腿/柜体轮廓是否变成其他型号；结构占位是否被当作柜子改写。
- 两机位是否能对应同一组物件、材料和位置。
- 图像视觉改善与几何保真分开评价。单看漂亮不判定合格。
- 评估为助手逐图视觉初审，尚待设计师复核，不能据此证明毫米尺寸正确；像素图无法证明不可见几何。
- 未通过时不扩展8视角、不接管物料清单和正式渲染；保留失败结果。

`node tools/render-benchmark/capture.mjs` 在Demo开发服务端口5179运行时导出基准图。AI图为独立输出，不覆盖基准图。本实验不是网页已接入云API的证明。

## 实际结果

已使用内置imagegen生成4张独立增强图（SI1.0/2.0 × 正面/右前机位），并对SI1.0右前图做1次单点修正；6张程序基准全部保留。图片已复制到项目目录，完整提示词见同目录 `prompts.json` 和 `correction-prompt.txt`。

主要可见物件数量大体保留，材质和阴影得到丰富。但两个右前机位出现左侧开箱桌形态改写；一次针对性修正恢复了灰色图中可见桌腿和开放下部，说明可交互修正，但不构成整组几何验收。隐藏区域、精确尺寸、品牌标识、跨视角分缝仍未验证。

结论：AI增强保留为概念图候选；暂不扩到8视角或替换正式3D渲染。下一轮应先完善场景中的真实道具几何，再验证更贴近最终交付的输入。当前程序材质图也使用简化道具，不应当作写实渲染质量上限。
