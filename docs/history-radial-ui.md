# 圆点径向历史图验收（2026-11-04）

对应 #145，按用户确认的径向图方案实现。

## 行为

- 空间、方案、三维效果、渲染使用四种圆点颜色，项目使用墨黑圆点；名称在悬浮或键盘聚焦时显示，草稿有独立标记与文字提示。
- 点击打开原节点，同时高亮祖先路径与后续分支。其它节点保留，只降低强调程度。当前名称、来源路径与颜色图例帮助定位。
- 选择和悬浮不改变布局或视口。拖动只改变目标节点，曲线跟随；拖动结束不会误触打开节点。位置沿用当前浏览器按项目保存的机制。
- “重置位置”恢复自动排列。放大、收起和显示已隐藏状态在节点切换时保留；工作台的节点编辑器仍按原 key 隔离草稿。
- 浅点阵仅作用于历史图。窄屏历史标签完整展示图形，其它标签保留原限高滚动。

## 验证

- 专项测试 21 项：标签、布局、关联范围、点击/悬浮不移位、拖动、保存/归位、重挂载后放大和视口保留、项目隔离、新增适配、删除后的偏移清理，以及原改名/隐藏/收起功能。
- 独立 API 3066、网页 5246、内存 PGlite，创建 14 节点多分支项目；浏览器 15 项检查通过，无未捕获异常。测试数据不写入用户项目。
- 逐一比对全部圆点的绘图坐标、屏幕坐标和 SVG viewBox；覆盖点击、悬浮、拖动后选择其它节点、刷新、归位，以及放大状态下跨方案和三维阶段切换。
- 1366×768、1440×900、390×844 检查无横向溢出，历史图完整可见；已人工核对普通、悬浮、放大、窄屏截图。
- 全仓 `pnpm check` 通过：shared 255、database 7、web 308、api 197，共 767 项测试；lint、类型检查及 `pnpm format:check` 通过。最终 CI 见 PR。

## 交叉复核修正

复核发现：本地存储不可写时，拖动偏移只保存在内存，旧实现却在结构变化时重新读取本地存储计算视口，可能裁掉已拖动节点。修正为同项目使用当前内存偏移，仅切换项目时读取该项目的保存位置。单测模拟 `setItem` 抛异常，浏览器禁用写入后拖出原边界并新建副本，均确认全部节点进入新视口，随后点击位置不变。

## 边界

用户主动隐藏/恢复分支的原功能保留。新增、删除或隐藏等结构变化会重新适配图形以容纳节点；仅选中节点不会重新适配。位置保存限于当前浏览器，未增加跨设备同步。资源目录只读，无依赖或迁移变更。

未改动受保护的 `plan-spacing`、`plan-resize-handle`、`plan-fixture`、`plan-embedded`、`plan-mounted` 类及平面导出 CSS（包括 `paint-order: stroke`）。
