# 第一阶段执行计划

## 目标

完成一个可演示的最小闭环：输入矩形门店尺寸，生成四个二维平面方案，选择一个方案并拖拽基础软装，生成标准平面图，选择 SI1.0 后输出一组示例效果图和 PDF。

## 阶段任务

### 阶段 0：资料和规则整理

- 整理 SI1.0、SI2.0 历史案例
- 建立基础软装资产表
- 确定一个标准矩形门店尺寸
- 明确区域、动线和最小通道规则
- 确定 8 个标准相机机位

### 阶段 1：二维方案原型

- 项目创建表单
- 四方案卡片
- 二维平面编辑器
- 软装拖拽、旋转、删除和替换
- 节点树和快照保存

### 阶段 2：标准图纸和风格分支

- 平面图尺寸标注和编号
- SI1.0 默认生成
- SI2.0 和双风格按需生成
- 基础白膜输出

### 阶段 3：效果图和交付

- 固定 8 机位渲染
- 物料清单自动汇总
- PDF 打包
- 方案确认和版本锁定

## 第一阶段完成标准

一个新项目从创建到 PDF 导出不需要人工修改源文件；用户能够回到方案 A、B、C、D 中任一节点重新生成；SI1.0 与 SI2.0 可以从同一个标准平面图独立创建。
