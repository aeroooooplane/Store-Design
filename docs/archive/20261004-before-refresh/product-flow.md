# 产品流程与分支树

## 主流程

```text
项目创建
  → 输入尺寸和约束
  → 生成 4 个平面方案
  → 用户选择一个方案
  → 网页调整软装
  → 生成标准平面图
  → 选择 SI1.0、SI2.0 或两者
  → 生成对应白膜
  → 渲染 8 个固定角度
  → 用户确认
  → 导出 PDF
```

## 分支树

```text
项目根节点
├── 方案 A
│   └── 用户调整版本
│       └── 标准平面图
│           ├── SI1.0 灰色调
│           │   ├── 白膜模型
│           │   └── 8 张效果图
│           ├── SI2.0 黑色调
│           │   ├── 白膜模型
│           │   └── 8 张效果图
│           └── SI1.0 + SI2.0
│               ├── SI1.0 效果分支
│               └── SI2.0 效果分支
├── 方案 B
├── 方案 C
└── 方案 D
```

任何节点都可以被重新打开，并基于该节点创建新分支。节点需要保存父节点、输入快照、生成参数、资源版本、状态和输出文件。

## 风格分支的算力策略

标准平面图确认后才进行风格生成。墙体、空间尺寸、软装摆位、基础模型和机位作为共享资产缓存；SI1.0 与 SI2.0 只分别生成材质、灯光、标识和效果图。

## 八个标准机位

入口视角、主通道视角、产品展示区视角、体验区视角、收银区视角、侧面视角、后场视角、鸟瞰视角。机位名称和相机参数应在项目设置中可配置。
