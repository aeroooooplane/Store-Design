# 轮廓误识别改进与48家开发复评（2026-11-05）

ONNX一致性已由独立PR #200修复合并。本轮在独立17训练/原3内部验证上做两组真实试训，冻结模型后完整复评48家；45家仅保留身份隔离索引，未读取其图像、几何或评分。旧48家用户标注、签名和答复不改写；无新增需用户裁决的业务歧义。

最终同预处理原始预测平均IoU **70.38%→77.79%**，37家改善、11家退化；**6/48**达到IoU≥90%。轮廓错误得到部分缓解，但没有全面解决，模型仍不具备生产接入资格。清理实验均值略高，却会误删有效平面，因此报告默认显示原始预测，清理不设为自动默认。

## 开发复评的三版记录

1. 首次冻结模型/评分/后处理哈希后，在v16用户参考上跑48家：旧原始69.41%、新原始76.85%、新＋清理77.64%。模型和后处理均不根据此次分数回改。
2. 目视发现PDF-079为黑底，增加无标签整页/边缘中位数判别，仅反色；该店新＋清理IoU降至0。此版本失败，完整保留，未冒充改善。
3. 黑底反色后增加固定0.5%对比度拉伸；先做灰底合成测试并记录PDF-079诊断，再重新冻结输入处理代码和完整48家复评。只有PDF-079触发反色；独立20家输入均无需反色，模型权重不变。这是**受开发集反馈影响的预处理改进**，不是新的盲测结果，不能泛化为未见数据精度。

所有版本保留相同48家、原参考多边形和坐标，不替换失败样本；48/48参考几何可评分。分割阈值始终0.5。原图像素栅格IoU不做平移/缩放对齐；不直接与旧矢量引擎的精确多边形IoU混比。本轮没有重新评分入口、量尺、家具或墙柱分类，也未修复/合并草稿PR #156。

## 最终48家结果

旧/新模型使用同一最终预处理，避免把预处理差异误当训练收益。

| 方案                   | 平均IoU | IoU≥90% | IoU≥80% |
| ---------------------- | ------- | ------- | ------- |
| 旧模型原始             | 70.38%  | 0/48    | 7/48    |
| 旧模型＋清理实验       | 72.85%  | 0/48    | 12/48   |
| 新模型原始（报告默认） | 77.79%  | 6/48    | 25/48   |
| 新模型＋清理实验       | 78.07%  | 6/48    | 27/48   |

新原始预测相对旧原始预测退化11家：NEW-020, NEW-023, NEW-065, NEW-098, PDF-079, PDF-098, PDF-140, PDF-302, PDF-321, PDF-351, PDF-407。完整48家逐店四方案IoU在同名JSON和外置`results.json`，不只汇报改善门店。

清理为8连通最大前景＋4连通内部填洞，不做凸包；内部柱洞本任务不扣除，不代表净可用面积。PDF-079校正输入后：旧原始78.65%、新原始74.66%、新＋清理50.16%，因新模型漏标使上下区域断开，清理误删上半部。该反例表明不能按清理后均值略高就自动采用清理。
