# 道具吸附空心隔板

用户要求添加的道具也能吸附到空心隔板。此前拖动只读取店铺边界及其他道具，未将 `layout.fixtures` 作为目标。

## 实现

- 普通道具在隔板外侧 100 mm 范围内吸附，按接触方向匹配边缘，不主动拉入隔板内部。
- 贴墙道具使用隔板四个外表面，正面朝外。新增、移动和缩放共用贴墙规则；默认安装高度不超过隔板，用户手设高度保留。
- 平面和三维沿用同一编辑 reducer，Alt 临时关闭吸附，拖动按手势撤销，位置和朝向使用原布局字段保存。
- 贴墙吸附与校验要求隔板面完整承托道具宽度及高度，过窄端面和过矮隔板不自动吸附。校验使用真实安装高度，手设超出隔板高度仍保留并提示。配件柜穿过外表面形成的缺口不算支撑，柜顶以上的实体可承托。
- 贴墙校验认可隔板外表面，删除隔板后恢复离墙提示。
- 不改变内嵌、吊挂、其他道具边线及斜墙的既有规则；不增加隔板随动绑定，不改变空心隔板开槽几何。目标是隔板矩形外表面，非柜体凹槽内部表面。任意斜转普通道具沿用原有平行斜墙吸附，未增加点角吸附。

## 验证

最终 `pnpm check` 与 `pnpm format:check` 通过：shared 263、database 7、web 346、api 220，共 836 项。CI 状态以 PR 最新提交为准。

65 项相关测试覆盖四侧接触、距离与范围、双侧朝向、默认/自定义高度、Alt、撤销重做及布局往返。浏览器 12 项通过，使用独立 3071/5251 与内存 PGlite，不写入用户项目，实际指针拖动核对平面与三维、保存新节点后重开。截图与脚本保存在工作树外，测试服务已停止。

主开发独立复核后，补充窄端面、低隔板、满高柜缺口和安装高度一致性回归，阻塞已解除。手设 2.1 m 的 0.5 m 画框不会吸到 2.4 m 隔板；2.6 m 隔板中穿出 1.9 m 配件柜时，自动高度画框实际以 2.0 m 置底贴到柜顶实体，吸附候选与落地使用同一个高度。最终全仓测试、格式和 CI 结果见 PR。本轮无迁移、依赖或资源变更，不改平面受保护类名及导出 CSS（含 `paint-order: stroke`）。
