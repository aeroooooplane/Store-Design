# 后续工作与交付门槛

更新：2026-10-04。早期阶段设想见 [历史计划](archive/20261004-before-refresh/roadmap.md)。

## 当前已具备

平面方案与编辑、分支和备份、22项清单驱动真实GLB、白模与八视角概念渲染、90件命名SU目录、45张纯净图例、360页标准阅读索引。当前架构和界面规范以对应说明为准。

## 优先继续

1. 选择一个门店、一个版本，核实闭合边界、入口、墙柱、尺寸和道具朝向，验证平面与三维一致。
2. 按同店同版验证 SI 材质和相机；先完成白模几何核对，再评估效果表现。
3. 按明确编号继续接入其余 SU；每件确认安装方式、单位、尺度、正面及材质后才开放摆放。
4. 补充尚无图例的模型，并根据实际使用需要统一矢量输出或施工图符号规则。

跨设备项目保存、独立后台渲染、完整 PDF 交付包属于未来方案，应单独定义数据迁移、失败恢复和验收范围。目前不以重新训练模型作为这些工作的前置条件。
