## 页面与保存

- 旧审核包只读嵌入并原字节备份；原轮廓以灰线显示。家具和入口各自确认，彼此不代签。
- 物体可点选、修改名称分类与明确尺寸、描多边形、拖顶点、删除；默认选择模式避免误描。原文尺寸与几何投影分开，未知资产和高度留空。
- 多入口支持折线、三点圆弧。代理补充方案需主动采用，原入口始终保留在原审核里。完整入口必须勾选明确确认并签名，未确认不进入完整评分。
- Ctrl+Z / Ctrl+Y、取消本次修改、审核人记忆、确认后返回列表；输入框保留原生文字撤销。取消恢复进入本店时的记录。
- “待确认问题”集中显示22项；回答未定也会保留原文，并不把门店变成完整验收。确认按钮要求问题已答，整店验收标记始终为false。
- 本机缓存独立键包含批次与数据指纹，不写旧审核缓存。导入严格校验身份、全集、原审核不变、几何与签名；导入前下载旧数据备份。跨目录/浏览器请使用导出包转移。
- 离线页面无网络调用，CSP禁止连接。云端识别未开启，本轮不包含外发路径。

## 文件与坐标

`整店标注草稿.json` 为可导入审核包；用户导出 `48家整店审核包.json` 后含两类审核状态及裁决。`入口复评参照.json` / 用户导出的 `48家入口复评参照.json` 可直接交给已合并的 `evaluate-entrances.mjs --reviewed`。

`annotations/<ID>.json` 保存原确认参照、原页像素多边形、米制派生坐标、每件原文尺寸、来源哈希及实例清单。米制原点为原确认边界左上，比例复用原确认量尺。`images/` 是48张原页PNG；`previews/` 是清洗裁切预览；`evidence/` 是原图加标注SVG；`inputs/` 保留14批描点输入、裁切矩阵和旧审核迁移参照。`核验报告.json` 给出计数与限制，`文件指纹.json` 逐文件保存SHA256。

复建命令：

```text
node --experimental-strip-types tools/recognition/whole-store-build.mjs --dataset <原candidates.json> --reviewed <原用户包.json> --reference <旧审核-v2.json> --inventory <裁切inventory.json> --manual-dir <人工批次目录> --out <新目录>
```
