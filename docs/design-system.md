# 网页视觉规范

更新：2026-10-04。项目采用瑞士风格的极简黑白界面。

## 视觉规则

- 白底、黑字，灰色用于次级文字、边框和辅助区域。页面结构通过网格、留白和字体层级表达。
- 无衬线字体；标题、表单和卡片左对齐。大标题与小标签形成明确层级。
- 按钮、输入框、卡片采用直角和细边框；主要操作为黑底白字，次要操作为白底黑字。
- 当前阶段通过字重、下划线和边框表达；错误同时提供文字和语义提示，不依赖颜色。
- 保持可见键盘焦点，窄屏重新排布，避免横向溢出。
- 模型照片、原始图纸和三维材质保留其真实颜色；纯净平面图例采用黑白线图。

## 唯一维护入口

`demo/src/styles/tokens.css` 定义共用主题变量；`workbench.css` 管理工作台布局；`model-library.css` 管理模型目录布局，`standards.css` 管理标准阅读目录。不要在 JSX 或 Python 里另写一套主题颜色。

工作台入口导入 `styles.css`。模型目录生成器读取同一套主题文件后内嵌，以兼容离线浏览。修改共享样式后执行：

```powershell
python tools/sketchup/build_model_catalogue.py
cd demo
npm.cmd run build
```

门店SI标准与网页视觉规范是两个独立层面；主题改动不应改变模型材质、尺寸或SI判断。

独立导出的SVG／PNG平面使用内嵌黑白印刷色，以便离开网页后仍可正确显示；颜色位于`demo/src/plan-export.js`，几何、比例和编号不随主题改变。
