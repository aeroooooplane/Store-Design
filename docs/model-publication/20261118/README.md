## 来源与构建

尺寸与排列依据SI2.0手册第127–129页。框体采用25毫米厚、5毫米可见边框，组内间距60毫米，正面为+Z，米制、Y向上、底部中心原点。三种组合的模型内容为画框，联名字标通过已有独立LOGO添加。

从 `asset-36929204` 网页模型保留照片材质和SketchUp重复UV，按原画面比例居中裁切。源组合包含两组不同缩放的A/B画框；本轮按标准尺寸重建银色框体，C/D为补建规格。七件交付为网页GLB及白模、材质轻量版，源SKP保留在原资产中。C/D示例照片沿用源模型，画面内容与手册第三种组合的示意照片有差异。

生成入口如下，隔离输出目录须为新目录且位于共享资源库之外。

```powershell
node apps/api/src/scripts/build-leica-models.ts <资源库根目录> <隔离输出目录>
```
