# MM93 赛车原版保真核对与历史候选

## 用户反馈后的更正

用户指出 #310 的修整版纹理与 Tripo 原版出入很大。此前叠加新贴花、移除原粗糙度贴图、降低法线强度与金属度、4K 降为 2K，改变了原始外观，属于本次处理错误。下面的 4.1 MB 修整候选已撤回，后续不以其作为入库源；历史记录保留供审计。

当前交付改为原始 Tripo GLB 的逐字节副本及原版离线预览，不做 GLB 重导出，不修改材质、UV、贴图分辨率或几何，不新增贴面。源文件本身已含完整三张 4K 基础色、金属/粗糙度和法线贴图，当前不需要用户补导出。原件 SHA256：`46ed38fb4e5a774e91e10264b20874a4c0a8584e655b5c680792c9b9e8700fef`，22,605,008 字节、501,846 三角面。没有重新提交 AI 生成。

`build-mm93-viewer.mjs` 默认校验原件 SHA，再内嵌原始字节；原件车头实际朝 −X，四视角随之调整，未更改模型坐标。深色预览背景与环境光属于查看器，不写回模型，也不声称与 Tripo 使用完全相同的环境照明。检查须独立提取 HTML 中的 GLB 并与源文件逐字节比较，另核对浏览器加载的 4096×4096 贴图、原 PBR 因子、单网格与完整面数。原版检查见 `original-validation.json`。

`repair-mm93.mjs` 默认拒绝执行；只有显式传入 `--allow-appearance-changes` 才可复现已撤回的外观实验，避免将其误用为保真优化。历史预览需要显式 `--legacy-repaired`，并显示“已撤回”。

## 改动及复现

1. `repair-mm93.mjs` 校验源 SHA，在红色壳体上投射五处贴面，修正两侧 Insta360 与车头/尾部 93；品牌采用已有 `packages/shared/src/facade/logo-art.json` 的海外矢量。保留黑色和金属区域，降低原有法线扰动和过强高光。数字采用清晰的斜体 93，不声称与官方专用字形完全一致。
2. 车头从 −X 转到 +Z，暂按整车及支架的全长 2100 mm 等比放大，底部居中。压缩前约宽 797.626 × 深 2100 × 高 1119.278 mm。
3. `optimize-mm93.mjs` 焊接、减面（目标比例 .25，误差参数 .0005）、清理与 meshopt 16 位位置量化，重新解码检查包围盒。结果 4,129,880 字节、150,643 三角面，6 个网格；源车壳、支架、轮胎与相机保留。
4. `build-mm93-viewer.mjs` 内嵌模型、Three.js 与 meshopt 解码器，无 CDN 或 HTTP 服务依赖，可直接打开 HTML，拖动、缩放或切换四个视角、五处标识显隐。

最终 GLB SHA256：`cf2a137b50b94fa8b2ed9a6309f236cac424638714cfd54d716f095da7572c9d`。细项见 `validation.json`。大文件与截图留在外置交付目录，不增加二进制 LFS 对象。

## 验证与限制

实际 GLB 已在 Edge / Three.js 中完成六向复核，包含正背面、两侧与两个斜视角。离线 HTML 已测试直接文件加载、四个相机按钮、贴面显隐、鼠标拖转和滚轮缩放；无页面错误或外部网络请求。压缩后最大包围盒偏移约 0.577 mm，底部约离地 0.073 mm。

本地 `pnpm check`（1063 项）及 `pnpm format:check` 通过；工具另做 Node 语法及拒绝覆盖/源校验。CI 状态以 PR 为准。

本件仍为 AI 重建的展示草模：油箱小字、车尾个别图案、车壳起伏和机械细节仍有失真，局部标识会随原壳体曲率变化。暂定尺寸没有厂家工程图依据，不能作为施工或制造尺寸。没有独立 SKP。此次只修整已有模型，没有重新提交任何 AI 生成或产生新的模型生成费用。

正式入库需先核定展示尺寸与可接受的外观，再由资源发布负责人分配 asset ID，准备独立 manifest/facing 增量及 conversion 记录，完成 catalog:white、catalog:finish、隔离 catalog:import、工作台缩略图/尺寸/朝向复验，随后按版本发布共享资源。本轮未执行该发布阶段。
