# 原图精细识别接入工作台（2026-11-12）

继承已合并 #223 的原图提取内核，本PR将图片上传、原图候选复核、量尺、修改尺寸与原生空间转换接入实际工作台。入口：项目 → 上传简图识别 → 原图精细识别。无需训练或外部模型，云端设置保持默认关闭；本接口即使云端设置开启，也不调用外部兜底。

## 实现与使用

1. 上传PNG/JPEG或浏览器转换的PDF页，点击“提取几何”。全尺寸坐标保留，超过4000边长或1200万像素明确拒绝；原始提取与SHA冻结。
2. 原图上选择/保留/排除候选、补矩形、拖顶点，量尺后可改宽深；支持撤销/重做与Ctrl+Z。名称、类别、道具高度可修改，未识别高度保持空白。
3. 描门店范围，独立设置开敞边与多个入口。中岛一键各边开敞；折线入口沿较短边界路径连接，不以入口倒推范围。墙体内部结构仍需后续补齐。
4. 保存到项目，刷新后从“继续已上传图纸”恢复。服务端按上传行事务锁与版本号拒绝过期写入，以stored_files登记不可变JSON版本，原始候选不会被人工改动覆盖；无新增数据库迁移。当前标签页另保留未保存草稿恢复，不能代替服务端保存。
5. 可导出审核包，也可导入同原图SHA的人工审核草稿。导入走同一服务端校验；来源不符、越界坐标、重复对象、不存在的候选均拒绝。审核人记忆在浏览器，备注用于集中歧义。
6. “检查空间转换”列出所有二维保留项，明确确认清单后才生成原生空间并返回工作台。矩形家具需明确高度；仍是占位体，不冒充真实资产。跨范围柱、非矩形道具、未知高度等保留二维；屏幕/灯箱不生成嵌墙实体。未知层高直接拦截。生成后原图草稿仍可回看/导出，原生空间可继续改尺寸。

## 六张真实原图验证

PDF-222、NEW-010、PDF-248、PDF-270、PDF-107、PDF-025逐张经实际工作台上传、点击提取，来源SHA和全部候选与冻结输出逐项一致。每张均验证选对象、保存刷新、导入人工审核、改宽100毫米、填900毫米测试高度、撤销重做和再次保存。测试高度/尺寸修改仅在隔离QA项目，不回写人工参考，不计入自动成绩。

PDF-222、PDF-107、PDF-025原图层高明确，显式确认保留二维清单后生成部分原生空间，均进入三维并保存刷新。每个QA空间只给一件家具填了测试高度，其余对象按清单留在二维；这证明转换链路，不是完整店铺已自动识别。NEW-010、PDF-248、PDF-270因层高未知正确拦截，没有填默认值。原生空间另验证改层高保存刷新；确认后源二维仍可读。浏览器错误0、外部请求0。

额外25项检查覆盖未保存恢复、描范围/量尺、错误来源拦截、六店审核页及导出；另6项检查覆盖两个折线入口、确认后二维可读与原生编辑。API7项覆盖持久化、过期写入、原始结果不变、输入校验、未知高度/比例拦截、屏幕与越界柱保留二维、幂等拦截及斜矩形/多入口；前端2项尺寸单测，原识别3项保留并增加1项本地默认不外发测试。
