日期：2026-09-23。范围：12家、四类各3家；不分析消防。用户要求忽略的6份冲突继续保留证据，排除本批，不再等待解决。

入口：[首批图纸图库](../资源库/99_历史归档/训练候选/batch01/index.html)。每家有原页、平面裁切、效果图（如已找到）与 JSON 来源记录；页号统一为 PDF 的物理页号，从1开始。

## 这批材料可以支持什么

12张已视觉选页的平面，11家各选2张效果图，共22张。北京首都机场T3仅收录第7页家具平面；已查看的候选图像页实际为施工图，暂不伪造配对。南宁万象城、马来西亚Pavilion Damansara Heights的第2页只是章节封面，真正布置图是第3页，已修正。

这是案例参考库，不是完成训练的数据集。SI与铺型沿用飞书总表；同一PDF内选页并不能证明与总表当前形象版本一致，也不保证平面和效果图逐个道具一致。本地PDF记录SHA-256便于后续识别文件变动，未对飞书附件做内容哈希比对。

## 暂不固化的尺寸

若干图纸出现1.8m体验桌、H900等标注，只是已观察到的规格，仍须按道具型号核对。澳门威尼斯人收银柜中英文长度不一致，暂不采用为标准尺寸。面积来自图纸标注，不代表净可布置面积；未录入的面积保留空值，不用效果图猜测。

## 下一步：先做4家精确标注

从四种组合各取一家：新疆宏景数码广场二店（PDF-194）、北京三里屯（PDF-051）、南宁万象城（PDF-083）、珠海华发商都（PDF-296）。它们先作为四个可解释模板；扶梯、曲线等复杂场地放到后续验证。

每家建立米制坐标：店铺外轮廓、入口/开放边、柱位、固定墙柜、体验桌、收银拆箱与仓储。逐项保存类别、中心位置、宽深高、旋转角、原页依据、置信状态；缺失尺寸留空，不按像素直接认定真实比例。确认至少两处尺寸后再校准比例。

之后接入Demo：输入面积/长宽及铺型 → 选取适用模板 → 约束摆放与碰撞检查 → 生成4个变体。已有SI1.0/2.0材质分支继续在平面确认后生成。当前这批工作尚未改变Demo生成算法，也没有微调模型。

## 可重复执行

- 在 `tools/pdf-review` 目录执行 `node batch-samples.mjs`：渲染选页用的低分辨率联系表。
- `node tools/pdf-review/export-reviewed-batch.mjs`：按已选页配置导出高分辨率图、来源记录及图库（任意目录运行）。
- 完整原页保留标注；平面裁切以去除右侧图签为主，不自动抹去尺寸。效果图当前保留完整页，避免误切内容；不是模型专用无边框训练图。
- 导出后检查12份manifest、12张平面、22张效果图及6条忽略决策；打开联系表和裁切确认没有丢失店铺主体。
