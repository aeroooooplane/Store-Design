## 样本与比对

准备同一渲染节点的 A、B 两个视角，以及另一个节点的同名 A 视角。准备一组升级前已保存材质渲染的视角和一组新建视角。两张合成背景使用不同尺寸、明显不对称的四色角标、横竖刻度和一条穿过 3D 物体轮廓的色带。用这些标记判断坐标方向、旋转中心、遮罩边界、跨视角串图和导出位置。主库和真实门店素材不参与测试。

## 接口审查项

- 冻结口径采用等比缩放，`transform.width` 为唯一尺度。空视角进入背景编辑即临时隐藏半透明墙，取消选图或退出空编辑后恢复。成功添加背景后默认保持隐藏，已有背景按保存的墙开关显示。
- 现有渲染以节点和视角 ID 定位，另有场景与视角签名用于判旧。建议新增独立的背景像素版本，覆盖替换、变换、遮罩和影响渲染的墙设置，将辅助线和选中态留在编辑状态。旧记录缺背景状态时应继续与旧签名兼容。
- 保存材质图时，应校验客户端合成所用的背景版本与当前版本。慢请求跨视角返回时应绑定请求发起时的节点和视角。背景图片引用与状态保存需要明确失败、重试和冲突行为。
- 照片坐标的单位、原点、旋转中心、缩放及裁切顺序应在契约固定。画布预览、最终输出和遮罩取样均用同一坐标定义。EXIF 方向按解码后的照片尺寸处理。
- 渲染 ZIP、交付和展陈都从当前材质图读取。现有交付会拒绝缺失或过期渲染，展陈会筛除过期材质图。测试需要覆盖三个消费者，防止新背景只在编辑预览中出现。

## 记录口径

每条记录候选提交、节点与视角、输入尺寸、复现步骤、预期、实际、结论和截图或导出路径。PNG 在无重采样区域比对像素，压缩重采样的文件对比色块与轮廓。旧视角兼容、跨视角串图、保存版本冲突和最终交付不一致均作为发布阻塞项。单元或 API 检查与浏览器验收分别记录。

基线 `47778b7a` 的 `renders.test.ts`、`deliveries.test.ts`、`display-api.test.ts` 在隔离内存数据库中共 12 项通过。该结果只覆盖现有渲染和导出行为。

核心 `02392dd2` 已静态审查。独立 Fastify/PGlite 实测同一修订并发保存返回 200 和 409，背景变更后的旧修订材质图上传返回 409，已有材质图在仅切换辅助线显隐后仍有效。旧无背景视角不带修订号上传返回 201，JPEG 上传返回规范化尺寸 450×720。同项目文件可显式复用到另一视角，跨项目绑定受服务端归属校验。上述结果不包含编辑 UI、成图和交付的组合验收。

发现一项并发读取缺陷。同项目重复上传相同图片会以项目 ID 和规范化图片 SHA 命中同一存储路径，再以普通写入打开已存在文件。隔离复现让第二个视角的上传停在截断之后、写入之前。原图片 GET 从 200/8127 字节变成 200/0 字节，已有视角可能解码失败。建议同内容命中时复用已校验的文件，或先写同目录临时文件再原子发布。回归应确保重复上传期间已有图片始终完整可读。

主开发添加原子发布后已隔离复测。第二个视角复用同一图片时，原图 GET 在上传暂停前后均为 8127 字节，内容逐字节相同，两个请求得到同一文件 ID。两个首次上传暂停在临时文件打开时，正式路径仍不存在。模拟 Windows 下第二个发布请求重命名返回 EPERM 后，两个上传均返回 201，正式文件 SHA 正确，临时文件清理完毕。测试使用显式同步屏障控制顺序，EPERM 为模拟故障。

### BG04 选图取消

修复后，空视角的页面添加入口、编辑工具添加入口均在接到非冒泡 `cancel` 后恢复三维查看，画布与进入前逐字节一致。已有背景的替换入口取消后仍处于编辑态，背景、墙设置和修订号保持一致。主动退出空编辑和进入即隐藏也复测通过。Chrome 验收通过文件输入派发与原生取消同型的非冒泡事件，不依赖操作系统文件对话框。证据为 `cancel-fixed.json` 和 `cancel-fixed-*.png`。

### BG05 旋转遮罩像素边界

在同一视角设置 20° 旋转、75% 宽度和闭合四点遮罩。成图后只删除遮罩再出图，变化共 218134 像素。以几何多边形外扩约 2 像素容纳抗锯齿，边界外仍有 12172 像素发生差异，其中 1805 像素的最大 RGB 通道差超过 2，最大差为 6（8 位）。原配置各自复渲两次，开、关两组分别逐字节复现。遮罩内实测可以盖住 3D，遮罩外零变化的严格标准未达到。

在相同 Chrome 中用生产合成函数、原照片与纯色平面替代 3D 图层后，遮罩外仍出现最高 6 个色阶的差异。空图层使用默认 Canvas 2D 设置也复现，改用 `willReadFrequently` 后该空图层对照为零差异，但纯色图层对照仍复现。差异可以在不经过 WebGL 的对照中产生，范围集中在照片边缘和纹理过渡，具体浏览器合成舍入路径尚未确认。导出仍一致地使用这一批最终图。证据为 `conflict-mask.json`、`mask-diff.json`、`rotated-mask-diff.png`、`mask-controls.json`、`mask-raster.json`。以上记录为修复前对照。
