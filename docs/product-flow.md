# 当前使用流程

更新：2026-10-04。早期流程设想见 [历史草案](archive/20261004-before-refresh/product-flow.md)。

1. 输入矩形空间参数和铺型，或按标准桌长估算比例。
2. 生成并比较四个候选平面，选择一个进入编辑。
3. 调整道具位置、朝向和数量，检查碰撞、越界与层高，保存快照。
4. 导出平面 SVG／PNG，或确认平面进入三维白模。
5. 选择 SI 参考环境，按同一布局生成八个机位的概念效果。
6. 下载八视角 ZIP，另存项目 JSON 以继续编辑或换电脑。

历史节点可恢复并复制为编辑分支；正在修改的草稿会自动保存。模型库提供90件SU浏览和下载，其中4项GLB已接入编辑器。案例证据及标准目录用于核对，不会自动还原门店几何。

浏览器项目绑定当前网址来源。使用固定的 `127.0.0.1:64071` 地址；换地址前导出备份。原始模型与图片不包含在项目 JSON 中。

各环节的操作和限制见 [使用指南](../demo/README.md)。
