## 推进顺序

1. **20家门店做大图和原页对照。** 先检查60张起始样本，再检查入选门店其余候选图。记录实际视角（门头、室内全景、鸟瞰、局部）、方向、完整性、清晰度、文字标注和黑边。当前不能用缩略图“看起来干净”代替此项。
2. **按门店核验版本。** 对照总表记录及附件，确认历史PDF对应哪次设计/改造；能获取附件时比内容哈希，不能只看文件大小。无法证明时保留待核，不覆盖总表标签。必要时请用户确认具体门店版本；原有6家冲突排除和未匹配项继续隔离。
3. **只为验收通过的图片写描述。** 包含SI、铺型、视角、可见结构与材质；不猜面积、未见尺寸或设计版本。碎片按原页位置恢复并验证；带标注图优先找同视角原图，不生成式涂抹后当真实样本。
4. **去近重复并按门店分组。** 同一门店、同图纸别名、相近版本和重复图族不得跨训练/验证两侧。SI2.0中岛只有4家候选，不能靠复制图片掩盖不足；最终划分和采样比例须在验收后的数据量上确定。
5. **小规模训练试验。** 以上检查通过后，结合本机已验证的4070训练环境准备小批次LoRA试验。先对比未微调基线和留出门店结果，再决定扩量；不在本轮修改训练配置或自动开跑。

第一阶段目标是带SI/铺型条件的效果图候选数据。若后续要求“依据平面尺寸生成可施工方案/SketchUp模型”，还需要平面、尺寸、结构及多视图配对数据，不能把效果图风格训练等同于空间尺寸推理能力。
