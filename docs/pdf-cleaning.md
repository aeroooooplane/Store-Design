## 这轮实际处理什么

读取已通过SHA256验证的原PDF，保留原件不变；相同文件只处理一份，保留所有来源别名。每页导出独立PDF及预览图，保留原页尺寸、旋转和来源页码。每个单页导出后重新打开检查，每份原件首页另外做像素比对；兼容性回退导出的页逐页比对。未对原图进行AI修补或去字。

图种分为封面、目录、设计施工说明、平面候选、立面候选、效果图候选、图像待分类、混排、电气和其他施工参考。自动分类用于排队，不能当作正式标签。新增页均保持 `training_eligible=false`，数据划分为 `unassigned`，避免未经审核的数据自动进入训练。

## 输出怎么用

- `index.html`：按门店或图种浏览，每张卡片可打开单页PDF及图块。
- `pages/PDF-编号/来源哈希/`：单页PDF、预览、带原始叠加层的裁切图、底层原始图片。
- `manifest.jsonl`：页面来源、哈希、页码、尺寸、旋转、候选类别、异常、裁切框及未核实的旧SI字段。
- `queues/`：图种清单，以及 `quarantine.jsonl` 异常/冲突隔离清单。隔离是逻辑标记，不删除原文件。
- `duplicate-review.json`：相同源文件、预览像素相同及近似页面的复核关系；近似不代表尺寸、日期、门店相同，不自动删页。
- `native-catalog/page-1.html`：底层原图去重图库。每张唯一图片只计一次，并保留所有出现位置。
- `native-catalog/visually-clean-si-unverified.jsonl`：经过大图视觉检查、但SI和版本仍未核实的图片。
- `native-catalog/excluded-or-separated.jsonl`：封面背景、带内嵌尺寸的图片、平面图、现场照片、解码失败等需要排除或另用的图片。
- `native-catalog/unreviewed.jsonl`：尚未完成视觉复核的图片。
- `summary.json`、`native-catalog/summary.json`、`verification.json`：实际数量及最终校验结果，避免混用样本批次和全量统计。

### 两种“去标注”必须区分

如果红色尺寸线只是PDF矢量叠加层，可以提取底层原始图片，不需要涂抹、生成或修补像素。例如PDF-001第3页的底层图片没有那些尺寸线。

如果红线、文字、图框已经烘焙进图片，提取后仍在；这类图像保持原状并标记排除，不伪造一个“干净版本”。底层对象也可能只是透明叠加层、掩膜、扫描平面图或封面照片，不能根据文件格式或成功解码就认定是效果图。

### 保守质量门槛

原图短边小于384像素标记低分辨率；长宽比大于4标记极端比例。这两个门槛只决定是否复核，不自动抛弃图像或批准训练。透明图原件保留透明通道，图库缩略图用白底显示，必须结合原页理解。

页预览的精确哈希及64位差分哈希（海明距离≤3）仅用于查重候选；底层原图用SHA256真正去除重复计数。跨店相同图片保留所有门店映射；后续划分训练/验证集时，确认的重复及同店历史版本必须在同一组。

## 异常与审核边界

部分PDF存在书签树修复提示，另有缺失对象、内容流异常或裁剪嵌套异常。内容相关警告保留到页记录并进入隔离清单。PyMuPDF遇到不能拆分的文件时用pypdf兼容回退，仍保留原件、异常标记和渲染检查。表单字段不简单删除：天津百脑汇案例用回退保留了可见外观及字段结构。

首轮60张定向底层图片加第二、三轮各200张顺序样本，共460张做过视觉审核；该样本不是随机准确率评测。大图审核与缩略图审核用不同状态记录。审核记录按图片SHA256保存在 `素材库/04_training/pdf-cleaning-v2/visual-decisions.json`，可重复应用。

本轮没有对所有图片做完整语义审核，没有做全量OCR、SI历史版本确认、CAD尺寸识别或几何标签生成。因此“第一轮清洗完成”不等于“所有输出可以直接训练”。

## 复现和继续

本机使用系统Python 3.13，依赖版本在 `tools/training/requirements-pdf-clean.txt`。无需占用GPU训练环境。

```powershell
python tools/training/clean-pdfs.py --workers 4
python tools/training/recheck-clean-pages.py
python tools/training/build-clean-catalog.py
python tools/training/verify-clean-pdfs.py
```

完成的原件按哈希与处理版本缓存，重跑不会重新导出完成的文件。最终验证仍会复查原件哈希、页数、单页PDF哈希和尺寸、唯一原图哈希以及图库本地链接。若改变处理算法版本或源文件版本，应使用新的 `--out output/pdf/cleaned-vN` 目录，避免混合实验。

`recheck-clean-pages.py` 针对本轮 `cleaned-v2` 初次比较出现差异标记的页面，用独立新打开的原件和拆分页重新渲染比对，保留初次标记和复查测量；不改PDF内容。复查记录在 `fresh-visual-recheck.json`。不要把这种画面一致性验证等同于图纸内容正确或SI标签正确。

大体积输出目录已从Git普通提交中排除，当前未执行commit或push。脚本和小体积审核记录可版本管理；派生PDF、原图及预览保存在本机。`cleaned-v1` 是171页试运行，`clean-diagnostic*` 为异常定位样本，不是最终数据集。
