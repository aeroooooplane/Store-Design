## 答复落实

`whole-store-decisions.mjs` 校验审核包与当前审核页批次、输入SHA和精确答复；只有已签核记录能派生属性。允许修改命名、分类、尺寸、新旧/空实/包覆信息及来源属性，禁止借此改写物体轮廓。路径用途必须与指定索引和原坐标匹配。

27条答复逐项归档，15项明确落实为23处物体属性和2条路径用途：NEW-020两段空心新墙；NEW-096四段墙高3000、空实待定；PDF-098两处后加空心包柱及右柱65寸屏幕；PDF-363保留现状通行线；PDF-407仅上方/左侧折线设为场地开放边，下方通行线保留。上一轮已确认的尺寸、屏幕/灯箱分类和结构柱同步落实。利旧单列为来源，不改变中岛桌类别。

派生包保留完整 `decisionSourcePack` 和逐项 `decisionLog`（原答复、审核人与时间、前后值），以 `decisionBatch` 隔离缓存和导入。用户原签名来源可回溯，自动属性落实不会冒充一次新的人工审核。原始导出文件另存，旧包不覆盖。

```sh
node tools/recognition/whole-store-decisions.mjs --bundle <上一轮交付目录> --reviewed <本轮用户整店包.json> --decisions <答复落实依据.json> --out <新目录>
```

输出包括可继续审核的黑白黄HTML、完整派生包、逐店像素/米制标注、清单、叠图、入口评分参照、台账和文件指纹。显示0条未答问题；不要求用户重复审核。
