# 24家空间与道具数量复评

本轮先纠正空间条件，再以同一批24家原审核家具数量生成候选。原轮廓并非缺失：24家都有闭合多边形，旧审核页黑线不醒目；实质问题是若干墙体、包墙未纳入避让。新增67段墙体/围护草稿、2处图注明确禁放区，轮廓坐标保持原值。新版用黑边黄虚线显示范围，墙柱、禁放区、家具分别记录；中岛边界不当实体墙。

## 数据与成果

- 固定24家（10边厅、11中岛、3专区），沿用48家开发子集。45家只读身份索引；原388对象、审核人、旧答复和24份标注字节不改。未训练，云端请求0。
- 提取177件家具实体；组合台一件多功能，附带座位与独立凳子不重复求和。这里的数量是本店原配置，不是全店统一必配标准。
- 外置最终包为 `layout-requirements-review-20261112-v3`，包含 `审核页.html`、`试点数据.json`、`复评汇总.json`、`原标注/`、`空间与需求/`、`工作台项目/` 和 `images/`。补标录点及复核记录单独保留，不回写已审核源包。
- 审核页可切换原图、旧候选、新候选，拖动轮廓/新墙顶点、描漏墙、撤销、记住审核人、保存后下一家、导出/回导同批修订包。修改几何后隐藏旧项目下载，提示重新排布；确认不等于业务验收或训练准入。

上一版“12家有收银”是全部门店中候选有该功能的数量；本轮10/22的分母限定为原图确有收银需求的门店，不能直接混比。72组无几何硬错误也不代表数量或经营动线通过。

新增工具只接收空间、实体功能/数量、尺寸和模型快照，不使用原家具位置。找不到组合模型时，只有原注可表达三维尺寸才生成明确的占位块。对明确长边采用5%或20毫米容差筛选模型，不能把900毫米收银台静默换成1800毫米。单凳不拿整组凳子代替。真实模型不缩放。

## 修正耗时

已记录补标后末20家叠图复核、补3处围护、两禁放区、柜体凹位修正、撤销不必要问题等区间：174.921秒（约2.9分钟），执行者为Codex代理，包含工具等待。首批64段录点及先看的4家叠图未可靠单独计时，不倒推或补造；用户人工净修正耗时为未知，不填0。页面新增活动计时，前台30秒无操作停止累计，切店/隐藏暂停，随审核包导出。QA模拟计时不计入真实人工用时。
