# 道具结构深化 v2

2026-09-23。交互入口：Demo → 打开真实图纸样本 → 点击道具 → 道具结构。

## 已实现

- 四类可选结构：开敞四腿桌、实体底座体验桌、封闭收银柜、开放层板配件柜。结构占位固定为实心体。
- 平面尺寸与位置保持独立，结构选择保存进项目 JSON 和历史快照。
- 白膜、SI1.0、SI2.0 使用同一函数生成道具部件；风格仅修改部件材质。删除旧渲染中额外的产品方块，避免结构柱顶部出现产品。
- 上海星光样本的两张体验桌使用实体底座。来源效果图支持可见底座形态，但不能证明隐藏构造。其余道具内部构造、板厚、底座比例均是假设，没有读取 SKP。
- `素材库/05_render_benchmark/s03-v2/index.html`：六张程序预览、两个机位、新旧白膜及原效果图对比。布局、部件坐标和图片 SHA256 同时存档。v1 文件不变。

## 验证与界限

12 项 Playwright 测试通过，生产构建通过。新增检查覆盖两种长宽方向的部件边界、四腿和底座结构、结构占位、快照恢复，以及三种风格的道具部件坐标完全一致。沿用构建的大包提示。

后续已新增两张 SI1.0 AI 材质验证图，使用内置 image_gen，没有进行模型训练。[查看验证页](../素材库/05_render_benchmark/s03-v2/ai.html)。原图、完整提示词、输入角色、检查记录和 SHA256 均保存在 s03-v2 目录。

助手目视初审：两个机位的体验桌底座和后柜开放层板仍可见，右前机位开箱桌保持桌下空隙；但台面边缘、接缝等细节有变化，遮挡部分无法核验。没有相机标定或几何精度证明，不批准为准确八视角交付。与 v1 的改善仅为定性观察，不是受控统计实验。

程序图是实时材质示意，尚不是写实效果图。柜体正面目前按长边默认朝 +Z 或 +X，旋转仍沿用长宽交换；需要任意朝向时应引入明确的朝向字段。道具几何一致不等于整幅场景完全一致：SI 预览仍有额外的墙面品牌标识和灯带。
