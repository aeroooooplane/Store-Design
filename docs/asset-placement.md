# 真实资产摆放清单

更新：2026-10-09（38 件 GLB 入库，正面方向初审）。90 件源模型中已接入 **22 件落地软装**，包括普通和亮脚中岛桌/开箱桌、配件柜、收银柜、坐凳组合及试飞台。未转换和悬挂件不开放摆放。

## 使用

模型库中有“前往工作台摆放”的资产可以加入平面。点击后先选择或新建平面，再点击“将选定模型加入当前平面”；打开链接本身不会修改项目。也可在平面编辑下方的“项目工具 → 查看90项资产目录”搜索编号或标准名称，点击“加入当前平面”。

道具保持源模型米制尺寸，不拉伸；包围盒可能包含凳子、陈列物、电脑和标签。目录中的 SI 是结构识别归属，不等于该模型已经通过品牌材质或制造验收。正面与材质仍标待核。大模型尺寸见目录，仅进入三维后下载所使用模型。

## 数据来源与再生成

1. `资源库/04_模型库/manifest.json`：已审核名称、变体、分类及源编号。
2. `资源库/04_模型库/<大类>/…/<模型目录>/网页模型/conversion.json`：转换与压缩记录、源 DAE/GLB 哈希、尺寸与坐标系；同目录 `facing.json` 记录正面方向。
3. `demo/src/data/placement-policy.json`：落地范围、用途映射、固定规划默认编号，以及旧版开放摆放的编号 `webAssets`。默认编号避免接入新资产后改变现有布局算法规格。
4. `demo/src/data/placement-manifest.json`：生成的摆放清单；前端不再维护四条尺寸常量。
5. `demo/src/data/asset-library.json`：90 件元数据目录，摆放状态由同一清单生成。

在 demo 目录运行：

```powershell
node scripts/convert-su-assets.mjs asset-编号
node scripts/compress-glb.mjs
node scripts/build-placement-manifest.mjs
python ../tools/sketchup/build_model_catalogue.py
npm run build
```

转换的环境变量与 DAE 来源见[网页模型说明](../资源库/04_模型库/_历史记录/网页模型说明-20261009.md)。转换命令需显式编号，不覆盖已存在结果；遇到失败先保留错误输出并检查，不能把不完整报告加入清单。原 SU/DAE 不修改。2026-10-09 起 38 件网页 GLB 经 Git LFS 提交。`build-asset-library.mjs` 依赖完整 90 件拆分清单，DAE 交付只含 38 件，不要用它重建目录。

生成器核对编号、源 DAE 哈希、GLB 头/版本/长度/哈希、源尺寸（容差 1 mm）和 asset-contract 坐标系；全部通过后才原子替换清单。转换和实际加载还会重读网格、核对尺寸及底部中心原点，失败时阻止导出，不能用占位块冒充完成。几何验证不代替视觉材质验收。

## 回退

保留旧清单和本机转换报告，回退代码提交即可恢复旧的摆放集合。若项目已使用新增编号，先导出该项目再回退；旧版程序会拒绝未知资产，不能将其静默替换。核心源文件和旧四件 GLB 均未覆盖。
