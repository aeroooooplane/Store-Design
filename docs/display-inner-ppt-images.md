# 交付PPT的内嵌托盘配图

## 复现与根因

在展陈任务生成PPT，或在渲染节点的交付中包含展陈PPT。原文件只有主机托盘图片、内嵌模块编号和数量明细，没有内嵌模块配图。预期为各桌附上与当前SI、所选方案和模块编号对应的图片。根因是`loadPhotos`只加载主机位，`DisplayDeckInput`没有内嵌图片，两个导出入口都没有向共用PPT生成器传入内嵌素材。

## 修改范围

在每张中岛桌的主机页之后附“内嵌托盘配图”页，编号、系列、桌号与模块顺序保留为可编辑文字。每页最多4个模块，超过4个时分页；边桌和无模块的桌子不增加该页。数量统计及Excel不变。

按SI和已保存方案加载图片：SI1.0与既有SI2.0使用旧图，SI2.0选择2026版时使用新图；旧规则不含2026配置时仍用旧图。只加载该次实际使用的编号，不跨方案借图，未知编号及缺失图片显示“暂无对应配图，请核对”。路径只由固定编号白名单组成，手填文本不会成为文件路径。

单独展陈与交付ZIP均通过既有`nodeDisplayFiles`/`buildDisplayFiles`/`buildDisplayDeck`共用链路补图，没有修改deliveries、Workbench、PlanView、white-scene或上传识别入口，也没有扩展完整版PDF。

## 图片来源与发布

共28个PNG（14既有模块、14新版模块），覆盖两方案2/3/4桌全部默认组合。新版从[指引](https://arashivision.feishu.cn/wiki/NwOVw5xTAiFcvGkn8TZcjEO1nNh)Docx rev4130第三节三张方案原图裁出，旧版从资源库既有的`配件模块/2桌内嵌托盘方案.png`等三张归档原图裁出；保留产品外观，不生成或重绘配件。旧2025云链接返回131006，未索取额外权限或改动云文档，旧图以已存在且匹配的本机原图为据。

逐图来源、裁切坐标、源图SHA、尺寸、字节及目标SHA见[发布清单](evidence/inner-ppt-release-20261105.json)。原图分辨率有限，部分模块仅55–70像素宽、52–80像素高，放大后略模糊；图片不会被宣称为高清。手填的非默认模块可能暂无对应配图。2026试摆/建议提示仍保留。

这是纯新增图片增量`inner-ppt-20261105`，不更换工作簿、不执行规则导入、不写数据库。开发产物在外置隔离目录，交唯一主发布窗口校验后写入共享资源；锁文件只增加28哈希及`displayIllustrations`版本，保留既有展陈rev4130、模型和540原图字段。回退代码与锁即可恢复旧导出行为，新图片保留以兼容已有文件，不删除原图。
