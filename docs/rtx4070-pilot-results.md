# RTX 4070 实际试训结果

日期：2026-09-25。结论：本机GPU训练、保存、重载流程已跑通；**尚不是可用于生产的门店设计模型**。

## 真实执行结果

| 项目 | SI1.0 | SI2.0 |
|---|---:|---:|
| 完成实验目录 | SI1.0-run02 | SI2.0-run01 |
| 优化步数 | 80 | 80 |
| 训练图 / 门店 | 10 / 5 | 8 / 4 |
| 验证图 / 门店 | 2 / 1 | 2 / 1 |
| 用时（载入、训练、出图、重载检查） | 60.4秒 | 63.4秒 |
| PyTorch峰值分配显存 | 2.89 GiB | 2.89 GiB |
| 验证噪声MSE：之前 → 之后 | 0.039151 → 0.039023 | 0.029408 → 0.028870 |
| 重载前后最大像素差 | 0 | 0 |

显存数字只统计PyTorch已分配内存，不包括系统、其他应用、CUDA上下文和保留缓存，不能理解为整机只用2.89 GiB。验证MSE只用了各1家门店、固定噪声抽样，不能据此判断风格质量或泛化。

基础模型：`stable-diffusion-v1-5/stable-diffusion-v1-5`；固定版本 `451f4fe16113bff5a5d2269ed5ad43b0592e9a14`，fp16 safetensors文件，BF16计算，512×512，batch1，LoRA rank4，学习率1e-4，梯度检查点。训练种子73，预览种子123。两份权重各256个LoRA张量、797,184个参数；全部数值有限，80条loss全部有限，训练/验证门店无交集。

独立环境：`tools/training/.venv4070`，Python3.12、torch2.6.0+cu124、diffusers0.35.1。没有修改旧CPU环境。下载完成后使用离线模式训练，没有上传门店资料。

## 产物和已知问题

根目录：`资源库/99_历史归档/训练实验/rtx4070-pilot/`。每个完成目录包含 `pytorch_lora_weights.safetensors`、`report.json`、`status.json`、80步 `loss.jsonl`、`before.png`、`after.png`、`reloaded.png`。权重仅与上述SD1.5基模兼容，不用于旧tiny模型、SDXL或FLUX。

SI1.0-run01的80步和保存完成，但离线重载因未指定weight_name报错。已保留原实验并标记failed；脚本修正明确权重文件名后，用新的run02完整重跑通过，没有覆盖旧实验。

仍缺正式数据资格：历史SI版本未经独立核实，样本仅11店22图，其中2店原PDF在当前仓库缺失；目前使用中心裁正方形、统一简略提示词和确定性VAE均值潜变量。这些是管线试跑限制，不是正式数据处理标准。暂不直接扩大到800步，避免仅记住少数门店。
