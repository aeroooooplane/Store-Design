# 入口、开放边与布局的关系

中岛店以空间范围和场地条件为起点。实际通行口随墙柜及软装布局变化，不能把某次图纸的全部入口线固化为未来排布的硬约束。

| 层           | 含义                                         | 调整家具后                     |
| ------------ | -------------------------------------------- | ------------------------------ |
| 店铺边界     | 已确认租赁或设计范围                         | 不随家具变化；增租需单独修订   |
| 场地开放边   | 与公共通道相邻且允许进入的边段，可多段或弯曲 | 通常保持；不能仅从未画墙推断   |
| 现状通行口   | 特定布局下实际可通过的开口                   | 需要重算或重描                 |
| 指定入口要求 | 业主明确的主入口、净宽或保留通路             | 作为独立规划约束，须有明确来源 |

本轮入口坐标原样保留为 `observed-current-layout` 参照。该标记只用于离线审核/复评，不向排布器注入强制入口，也不把每条中岛边当成入口。仅员工、消防或辅助出口的已答结论继续保留，不能并入顾客入口分数。

当前评分比较相同原图布局：按已标路径计算覆盖率。只有显式签署“通行口齐全”才计算完整精确率、召回率和 F1。部分参照也导出最新路径，保留旧路径在 `originalEntrances`；版本 2 表示支持多段/曲线，并不表示完整。

后续布局验证顺序：开放边与公共通道关系 → 扣除墙柱、柜体及软装阻挡 → 检查净宽、可达性与主通路 → 展示实际通行口。消防合规及通道规范不能仅凭本图纸标注自动断言通过。本轮没有实现通行空间推导器。

包墙另建外包轮廓，并关联原墙柱核心：核心、包板、内部空腔分别记录，不从填充颜色推断材料、空实或承重。按已确认项目规则，原柱/管井扣面积，后加包板等只避让、不扣面积；多层轮廓不能相加重复扣面积。原图不足时保留未知，不把未知按实心处理。

PDF-261 已答“增租纳入”是边界变更证据，不能通过延长入口线代替租赁边界校正；原轮廓签核暂保持，单独进入下一轮边界差异检查。PDF-398 的“四周开放”是开放关系证据，不等于四周都必须保持为空。利旧是物料来源属性，不是家具类别。

## 本轮接收与复评

48 家实包中 28 家入口改变，75 条路径完整保留。固定输出重放：基线/候选边界合格 11/48 与 17/48，闭合均 40/48，比例均 43/48；更新参照后的已知路径覆盖率均值 6.109% 与 7.913%。之前旧参照分别为 8.266% 与 9.867%；这是参照更新导致的分数变化，本轮没有改善识别引擎。完整入口参照 0，完整 F1 及三项联合通过率仍不可用。

未闭合仍为 NEW-019、NEW-096、PDF-050、PDF-073、PDF-079、PDF-096、PDF-217、PDF-417；PDF-098、PDF-090 的候选退化未解决，#156 保持草稿。

PDF-363、PDF-407 的新通行线与旧边界校验不符。复评分别校验原轮廓/原入口与新通行路径，保留 `referenceWarnings`；不吸附、删除用户描线，也不降低原轮廓校验门槛。仅在显式 `observed-current-layout` 且带原入口记录时采用此流程。待核对其通行线位置及边界关系。
