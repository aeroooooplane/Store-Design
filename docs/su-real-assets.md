## 调整后的实现方向

平面图负责空间边界和摆放坐标；每个道具绑定真实资产编号。真实 SU 几何转换为 GLB 后按原尺寸放入场景。白膜使用同一网格，仅替换为中性白材质；后续材质预览也复用这一网格。图片用于风格参考和核对，不负责生成道具结构。

1. 读取组件定义与实例层级，记录来源路径、定义标识、实例变换和可见性。不要把螺丝、产品零件、组装整桌混在一个道具类别里。
2. 优先挑选体验桌、配件柜、收银台和开箱桌；先完成一张体验桌的端到端验证，再批量拆分。
3. 道具档案记录名称、类别、SI 标签（未知可留空）、原始来源、精确边界、正面方向、原点、模型和材质文件、验证状态。材质颜色本身不能证明 SI 版本。
4. 转换时统一到米、Y 轴向上、底部中心原点，保留实例缩放与嵌套变换。先核对原模型长宽高及材质，不按目前占位盒任意拉伸真实模型；不匹配时应改布局或选另一规格。
5. 网页按需加载 GLB，模型加载成功后才替换占位物。加载失败必须显式提示，不能把占位物当成真实模型。白膜替换材质需要保留由透明裁切表达的实际轮廓，避免把镂空变成整片白板。
6. 以真实模型边界更新平面占地和碰撞检查，再从同一场景输出八视角。原布局与新真实资产布局分开保存版本。

## 当前依赖与可执行交接

需要一个兼容的 SketchUp 桌面环境，或者已获授权的官方 Desktop SDK。官方 C API 支持独立读取 SKP，不必依赖桌面交互，但本机尚无该运行库：

- [SketchUp C API](https://extensions.sketchup.com/developers/sketchup_c_api/sketchup/index.html)
- [官方 SDK 获取入口](https://developer.sketchup.com/)

若使用有 SketchUp 的电脑：把现有 `tools/sketchup/export_selected.rb` 带过去，打开原模型后运行 `InstaAssetExport.inventory`。随后在模型根层选中一张完整体验桌，执行 `InstaAssetExport.export_selected`，交回生成目录中的 `prop.dae`、贴图、`prop.skp` 和 `metadata.json`。脚本尚未在 SketchUp 内运行验证，先导出一个组件。

若选择的桌子位于嵌套组中，现有脚本会拒绝编辑状态下的导出；应在独立副本里整理一个完整道具到根层，不修改原文件。也可由操作人员单独导出这张桌子的 GLB，保留单位和尺寸说明。

目前尚未将任何真实 SU 网格放入白膜。不要用嵌入缩略图或参数化几何冒充这一步完成。

复现预检：`tools/training/.venv/Scripts/python.exe tools/sketchup/inspect_archive.py`。
