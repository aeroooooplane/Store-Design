# 中岛台地与银色收口

两版中岛店台地均高30mm，银灰哑面不锈钢压边总宽80mm。台地顶面沿用道具地面零点，外部公区基面低30mm，不改道具坐标及安装高度。

用户最终确认两版SI都采用SI2.0手册的坡段尺寸：

- SI2.0手册PDF第142页“地面与公区（中岛）”剖面给出30mm高度、50mm坡段水平投影，因此使用约30.96°坡面，平段30mm。
- SI1.0手册PDF第145页给出银灰色不锈钢包边示意，第114页材料表给出80mm压边宽度；用户明确指定SI1.0同样采用50mm坡段水平投影、约30.96°，平段30mm。

切换SI风格时同步更新收口几何，白模和材质视图都保持银色。轻量展示不包含图中5mm起口的加工细节，不作为加工节点图；极尖角限制斜接长度以防长尖刺。
