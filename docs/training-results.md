# 首轮本地训练结果

用户确认同时需要布局与效果图风格训练；本机无NVIDIA GPU，随后明确先完成本机可执行部分。本轮没有租用算力、付费调用或上传门店图纸。

## 已完成

1. 布局标签12家，11家面积可用；目标是产品体验桌数量，收银/开箱桌排除。11家训练、3000次梯度更新，留一验证MAE 0.455张，折内均值基线0.691张，取整命中7/11。该模型尚未预测坐标、方向、柜体类型或整张平面。
2. Demo增加默认关闭的“实验：参考已训练的体验桌数量模型”。12–141.5㎡内预测数量，位置仍由规则安排并检查碰撞；超范围回退。每个分支保存模型版本、数据哈希、建议数量和实际放置数量。风格仍在白膜后选择。
3. 四家几何草标注：三里屯和珠海有可复核的主要尺寸链；新疆与南宁仍有坐标/边界缺失，所有几何明确不具备训练资格。
4. 风格数据22图，9家18图训练、2家4图验证；按门店切分，6份冲突排除。SI1.0和SI2.0分别完成80步tiny基模LoRA训练，保存safetensors权重、逐步loss、前后预览和评估记录。
5. SI1.0固定验证噪声MSE 1.0790→1.0533；SI2.0 1.0782→1.0523。两者保存后重载的固定种子预览最大像素差均为0。该指标验证工程流程，不代表风格学习效果；tiny预览为噪声状图像，不能用于门店设计。

## 未完成与明确限制

正式SD1.5/SDXL风格模型尚未训练；tiny权重不能用于SD1.5。SD1.5 GPU训练命令已准备，但未在GPU机器验证；当前脚本不支持SDXL。真实SKP资产、完整几何生成训练、跨视角一致性和施工级出图不属于本轮已完成内容。

小样本带来明显限制：每个SI只有1家验证店；面积回归忽略铺型与门店障碍；SI总表标签与历史图纸未逐店核对；数据不是设计师复核后的正式训练集。训练损失下降不能证明规则正确。
