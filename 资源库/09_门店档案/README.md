## 编号

- **source_id**：沿用旧编号。PDF-001~418 来自门店资源索引，NEW-006~101 来自 10-09 交接包；NEW-001~005 是不建档的 RAR / PPTX，NEW-027 是飞书台账。
- **store_id**：直接沿用主来源的 source_id（来源清单里的 `archive_source_id`），不另编号。档案目录名为 `store_id__主文件名`，例如 `PDF-001__上海TPY中心/`。

## Git 边界

只提交 JSON / CSV / MD。PDF、PNG、JPG、SVG、`renders/`、`evidence/`、`_cache/` 都由 `.gitignore` 排除（主仓库的 `.git/info/exclude` 里同步了一份），需要时用脚本从原图纸重新生成。
