# 产品与陈列（展陈规则）

本目录是展陈方案的规则来源，内容转写自飞书《影石专卖店中岛桌&边桌&配件柜展陈指引》（https://arashivision.feishu.cn/wiki/NwOVw5xTAiFcvGkn8TZcjEO1nNh）。需求见 [docs/display-plan-requirements.md](../../docs/display-plan-requirements.md)。

| 内容 | 说明 |
|---|---|
| `展陈规则.xlsx` | 规则本体，由展陈负责人维护；`pnpm display:import` 导入数据库 |
| `托盘照片/SI1.0`、`托盘照片/SI2.0` | 指引第二节各托盘的实景图与效果图（宽 1280 像素以内的 JPEG），PPT 中每个陈列位旁的照片 |
| `配件模块/` | 指引第三节的外框与 A / C / D 模块实景图，以及 2 / 3 / 4 桌内嵌托盘方案原图 |
| `指引原图/2026-10-13/` | 转写时依据的规则示意图和数量明细原图，用于日后核对 Excel |

## 指引更新时怎么做

1. 打开飞书指引的最新版，对照修改 `展陈规则.xlsx`：先改“说明”中的版本日期，再改“版式”“陈列组合”“数量核对”等工作表。新托盘的照片在飞书中点开图片下载，放进 `托盘照片/`，并在“照片”工作表登记。
2. 运行 `pnpm display:import`。导入会做两件事：
   - 核对每种桌数、市场、竖横版下各位产品与托盘之和是否等于“数量核对”（照抄指引的产品 / 托盘数量明细），不一致就拒绝导入，并指出哪个工作表哪一行有问题；
   - 列出与上一版相比改了哪些桌、哪些位。
3. 把新的 Excel、照片和本次的指引原图（建议放到 `指引原图/<版本日期>/`）一并提交。

已生成的展陈方案保留生成时的规则版本，不会被新版改动。

## 工作表

| 工作表 | 列 | 说明 |
|---|---|---|
| 说明 | 项目、内容 | 版本日期、来源、陈列说明、数量规则、填写说明 |
| 产品型号 | 编号、类目、型号 | 与指引“产品数量明细”的型号一一对应 |
| 托盘种类 | 编号、名称 | 与指引“托盘数量明细”对应（名称已统一：AG 代替 AVBU） |
| 陈列组合 | 编号、位上显示名、构成、托盘 | 一个托盘位上放的内容；构成写“产品编号*数量”，多个用分号隔开，如 `x5*1; x4-air*1` |
| 版式 | 桌数、市场、版本、桌号、位号、陈列组合、明星位 | 2 桌与边桌的市场填“通用”，3 / 4 桌分“国内”“海外”；位号见下 |
| 配件模块 | 模块号、系列、尺寸类别 | 指引第三节 |
| 桌号模块 | 桌数、桌号、模块 | 每张中岛桌中间放的配件模块 |
| 照片 | 陈列组合、SI、类型、文件 | 类型为实景图或效果图；文件路径相对于本目录 |
| 数量核对 | 桌数、市场、类别、编号、数量 | 照抄指引的产品数量明细与托盘数量明细 |

位号：竖版为 L1–L3、R1–R3（从远到近）和 E（端头，明星位，朝入口）；横版为 E（端头，全店统一一侧）、T1–T3（远侧一排，从左到右）、B1–B3（靠主人流一侧，B2 为明星位）；边桌为 S1–S3。

## 转写说明（2026-10-13 版）

- 产品以指引第一节为准；第三节只用来确定桌子中间的配件模块。
- 指引原表“4 桌（海外）托盘数量明细”重复列了一行“AVBU pac air 托盘”，去掉重复后合计 28，与总计一致。
- 海外 4-3 桌：竖版明星位是 AG、横版明星位是 AG Pac Neo，两版不一致，按原图转写。
- 美国门店不适用“海外”版式，单店单议。
- 指引中“AG Pac Neo / AG Pac Air”托盘暂无照片。
