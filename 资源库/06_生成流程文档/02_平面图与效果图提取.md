# 有利于平面生成的切分与标注方案

## 先确定训练任务

本项目建议先学习“给定门店边界、入口/墙柱/固定设施、道具需求和已核准规则，输出每件道具的类别、型号、位置和朝向”。输出采用可编辑布局JSON，再由现有程序绘制平面。仅把PDF拆成图片，不能自动获得尺寸准确、可编辑、能校验的训练目标。

Graph2Plan以边界和布局图约束生成平面；ATISS使用带类别的3D包围盒监督生成场景。它们支持结构化数据的重要性，但研究场景不等于本项目门店，本建议是结合当前代码与资料做出的方案，不保证直接套用其预训练模型有效。

- [Graph2Plan原论文](https://arxiv.org/abs/2004.13204)
- [ATISS原论文](https://arxiv.org/abs/2110.03675)

## 一家店、一个版本、两层成果

**人工查阅层**：每店一份平面PDF、一份效果PDF，按原页序汇集，保留标题、尺寸及图号。原始边界与家具平面标清用途；装修前后、不同楼层或备选方案不能混为同一个目标。

**训练数据层**：在 `90_处理过程与审核/训练标注/<store_id>/<version_id>/` 保存以下文件：

| 文件 | 必须表达的信息 |
|---|---|
| `source.json` | 来源PDF哈希、物理页码、图号、裁切框、页面旋转、版本证据、审核人/时间 |
| `input.json` | 边界多边形、入口线段/门扇方向、墙柱多边形、固定设施、区域需求、道具数量/规格、规则出处 |
| `target-layout.json` | 每件道具的asset_id、功能类别、中心x/z、宽深高、yaw、真实占地、固定/可移动标记 |
| `geometry.svg` / 掩膜 | 分开的墙柱、入口、固定物和可移动道具层，不把尺寸线当作墙 |
| `evidence.png` | 保留尺寸/标题的证据图，用于核对比例和版本 |
| `geometry.png` | 与输入严格对齐的几何图；仅移除有明确图层依据的标注，不使用AI补画 |
| `review.json` | 尺度、闭合边界、碰撞、通道、标注完整性、争议字段及训练准入状态 |

每个文件使用统一坐标系：单位米，平面x/z，竖直y，yaw约定固定；记录PDF点坐标到真实坐标的变换。优先CAD/SKP精确几何；PDF用明确尺寸标定，至少交叉核对两个方向，不能靠面积或图片长宽比猜尺寸。未知字段填null。

## 具体切分规则

1. 先识别图纸目录、图号、标题和版本，定位原始/结构平面、家具布置、门店效果页。自动识别只产生候选队列。
2. 单页中有多个店型、不同楼层或方案时，按独立图框拆成多个区域；不要把多个布局缩进同一个训练样本。
3. 保留完整原页证据，另裁切门店边界及必要的外围尺寸。所有输入/目标层共享同一裁切框、方向、比例和像素变换。
4. 先保留矢量PDF，再按明确DPI生成模型需要的图像。保持纵横比，用留白补齐尺寸，不拉伸；真实坐标独立于像素分辨率。
5. 家具统一关联现有asset_id。同类不同尺寸分别标注，不能用包围盒总高替代桌面高度；椅子组合、悬挂件、柜门开启占用需分别说明。
6. 效果图作为外观和材质参考，记录来自哪页、哪幅、是否真实对应此平面。没有同一几何和相机证据时，不组成“平面到效果图”的严格配对训练样本。
7. 每店最终PDF的页清单和训练样本清单分开保存，避免把查阅页数当作训练样本数。

## 准入和评估

先做5到10家具有明确版本与完整尺寸的人工试点，这是建议的工作批次，不是模型收敛所需数据量。当前五店案例可作为选页起点，但历史记录明确说明几何尚未闭合，不能直接宣布训练就绪。

同店所有版本、视角、近重复及同哈希来源必须进入同一个训练/验证/测试分组；不得随机按页切分。比例按可用门店组数确定，测试集在规则调参前冻结。人工合成或程序生成样本单独标记，不能混入真实店铺测试集。

在现有约束生成器和相似案例检索基线上评估：边界越界率、碰撞率、入口/通道违反率、道具规格和数量符合率、物理坐标误差、可编辑性与人工评审结果。阈值必须来自已核准店型规则；本文件不编造消防或品牌标准。
