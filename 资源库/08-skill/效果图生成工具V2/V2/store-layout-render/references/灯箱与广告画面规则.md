# 灯箱与广告机画面

适用：特殊尺寸、缺少贴图或用户要求补充内容的灯箱、电子水牌、电视机和广告机。用户已指定画面时优先使用，不改动设备数量、位置、方向或柜体结构。

## 先识别显示面，再选图

- 按设备实际可视区域的宽高判断横版/竖版，不按截图透视或设备名称猜方向；记录对象 ID、可视宽高、目标宽高比和朝向。
- 横版显示面用横版画面；竖版显示面必须用竖版原图或品牌官方竖版适配稿，不能将横图旋转、拉伸或大幅裁切后冒充竖图。方形、超宽等异形比例选相近比例素材；没有合适内容则列出待补，不交付明显变形的画面。
- 在方向一致且比例接近时可等比缩放并小幅裁边，但必须保留产品、人物主体、文字与 Logo；不得拉宽、压扁、镜像、切掉关键内容或重复铺贴凑满屏幕。

## 联网获取与使用

可直接联网搜索合适的品牌、产品或运动场景，优先官方产品页、新闻/媒体素材和用户授权的品牌素材库。访问来源页核对原图尺寸与内容，不把搜索缩略图当成高清原稿；遇到登录或付费限制不要绕过。

选图须与门店所属市场及展示产品相符，海外注意语言和英文 Logo，国内按中文组合字标规则核验。多块屏幕优先选择不同且协调的画面；同一设备在不同视角须保持同一贴图，不能每个视角更换内容。

仅在工具和来源允许的条件下获取、嵌入素材；不能通过下载绕过显示限制。联网可见不等于可商用：未明确授权的图片只作为方案演示素材标注，施工印刷或公开投放前需替换为授权高清稿，不擅自去除水印。

## 记录与验收

记录每块显示面的对象 ID、横/竖方向、目标比例、素材原始像素尺寸、来源页 URL、获取日期、授权状态和裁切方式；可获取文件时保留素材及哈希，随项目记录交付。

渲染前检查：竖屏确用竖图、横屏确用横图、无变形/关键内容裁切、画面朝向与用户要求一致，分辨率满足当前预览或正式输出。找不到合适或可用素材时明确列为待补，不声称已完成正式画面。画面变化须更新场景/贴图哈希，不能沿用旧缓存。
