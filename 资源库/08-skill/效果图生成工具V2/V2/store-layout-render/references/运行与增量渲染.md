# 换电脑复用与增量渲染

> 当前出图先执行 `品牌Logo规则.md`：默认西安场景和旧 `logo_full` 属历史素材，下面直接运行示例只可作环境/历史复现测试。生成当前方案须先在项目副本中换为官方“影石Insta360”，检查全部可见标识并使用新输出目录；普通渲染脚本不自动换标或识别品牌。仅归档历史成果无需重渲染。

这是 V1 直接 Blender 调用方式的兼容参考。V2 默认使用统一入口，最新预览、状态及恢复规则见 **V2操作指南.md**；以下历史续跑描述不应覆盖 V2 的配置归属校验。

## 依赖

推荐与验证环境一致的 Blender 4.5.13（Windows x64）；其他版本先试渲染，不承诺逐像素相同。Blender 请从 [官方发布目录](https://download.blender.org/release/Blender4.5/) 获取。渲染脚本用 Blender 自带 Python，无需额外 pip 安装。原始 PDF 的新项目解析才需要 pdfplumber 等。

本包不捆绑 Blender 或 SketchUp SDK 二进制。复现示例只需 Blender，不需要安装 SketchUp、SU 插件，也不需要重新打开 1 GB 以上的全套模型。缓存道具与最终场景的纹理已打包；原始 SKP 用于之后补充新型号。

## 给 Codex 使用

将整个 `store-layout-render` 文件夹复制到目标项目 `.agents/skills/`，保留内部 assets、scripts、references。也可以不安装，直接给 Codex 整个目录路径并要求读取 SKILL.md。安装后新开项目会话发现技能；用 `$store-layout-render` 指定使用。模型和素材较大，分享必须连同 assets，不能只复制 SKILL.md。

## 直接运行，无需反复问 AI

下面假设把分享目录复制到了 `E:\门店工具`，Blender 路径需替换为接收者自己的路径：

```powershell
& 'C:\软件\Blender\blender.exe' --background --factory-startup --disable-autoexec --threads 4 --python-exit-code 1 --python 'E:\门店工具\store-layout-render\scripts\render_scene.py' -- --job 'E:\门店工具\store-layout-render\assets\xian\job.json' --out 'E:\门店工具\新输出\试渲染' --profile draft --views 01_storefront
```

默认一视角输出材质、白模两张，draft 为 600×400、各 8 采样。命令成功会输出 RUN_SUMMARY；非零退出码应先解决错误，不继续批量。

正式十视角及俯视校核：将 `--profile draft --views 01_storefront` 改成 `--profile final --views all`，并换一个新的输出目录。正式材质 1800×1200、64 采样；白模 16 采样。合计 21 PNG，其中 10 材质、10 白模、1 俯视校核。

只补两张相机：`--views 12_new_left,13_new_back`；ID 必须先存在于 job.json。`--mode material` 可以只出材质图；几何校核阶段不建议省掉对应白模。

## 缓存、版本与防覆盖

源 scene.blend 保持不动；相机可在 job.json 独立配置。缓存由源场景内容哈希、当前视角、参数、脚本版本、Blender 版本和实际图像哈希共同决定；场景任何改动会使旧缓存失效。增添相机不改变原场景，所以原有相机仍可跳过。

同参数重复运行自动跳过已验证图片。图片损坏、配置变化而目标同名时，脚本停止并要求新的输出目录，不覆盖旧交付。新增两个视角可写入原输出目录；更改旧视角则写入新版本目录。旧版图片没有缓存记录，不能仅凭文件存在跳过；可直接沿用旧交付文件夹，仅把新增视角渲染到新目录。

每张成功后保存 `render-manifest.json`，包含图片哈希、相机矩阵、场景哈希、显隐列表、耗时；`last-run.json` 是最近一次汇总。中断可重跑；若中断恰好留下未记账图片，先将该图片移到备份目录，再重跑，不盲目信任半成品。不要并行启动多个进程写同一个输出目录。

新增相机示例（添加到 views）：

```json
{"id":"12_new_left","position":[-8,4.4,3],"target":[2,4.4,1.1],"coordinate_system":"pdf_y_down","lens":28}
```

已有相机可引用 camera 名；新位置必须声明坐标系，不能猜测。剖切用 hide_prefixes 显式配置，不复制为一般建筑场景。

## 从道具重新构建西安示例

`assets/xian/workspace/store_effect_poc/build_xian_v2.py` 保留本次已验证的专用构建逻辑（历史文件名 v2，实际输出已修正为 v3），路径相对此示例工作区。它读取同目录场景 JSON 和 `tmp/xian_skp/assets/*.blend`，不是通用建店程序。先 `--build-only`；它会在该示例工作区 outputs 新建/更新文件，运行前备份同名结果。
