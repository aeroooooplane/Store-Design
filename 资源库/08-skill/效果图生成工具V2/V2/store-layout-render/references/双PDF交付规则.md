# 双 PDF 交付规则

2026-10-09 用户约定，适用于新生成方案；不追溯改名或覆盖历史交付。每套方案同目录同时保存两份 PDF，使用同一冻结布局、同批次图片；不得仅给完整版改名后冒充展示版。

## 文件命名

- 完整版：`00-影石xxx店完整方案.pdf`。
- 展示版：`影石xxx店方案.pdf`。
- `影石xxx店` 使用该项目实际完整店名，不保留占位符 xxx，不重复追加“影石”或“店”。没有真实店名时使用如“影石概念专区店”，不虚构地址；预览状态须在标题中明确标注，不能假称正式交付。

## 两版内容

完整版保留带尺寸、图例和设计说明的平面页、效果图总览、每个正式材质视角的独立大图页，以及本次需要的白模/俯视校核记录。必要假设和未核实事项保留在完整版与项目记录中。

展示版严格按以下顺序：
1. 第一页仅店名标题、平面图及图例。平面内部尺寸、道具名称与编号属于图纸内容，可保留；移除“布置逻辑”“确认重点”等侧栏和说明段落、原模型参考图、封面、目录。
2. 后续每页一个不同角度的材质效果图，保持原始比例；可用简短视角标题和页码。不得插入效果图总览、白模及白模总览、纯校核记录页或额外文字说明页。

展示版不是把完整版首张整页截成图片；应从同一结构化平面重新排出简洁首页。复用原始材质单图，不用总览缩略图作为大图，不为两版额外渲染。

## 校验与对话

逐页渲染检查两版 PDF：中文、比例、裁切、排版及页码正确；展示版页数为 1 加实际选用材质视角数，后续每页对应一张原始材质图，并覆盖本次所有展示视角。确认简洁首页没有侧栏，展示版没有白模或总览。保存两版页序/视角映射到交付记录。

归档到用户指定输出方案目录的独立门店文件夹，并核对文件完整性。对话默认输出完整版的可用 PDF 入口；展示版留在同目录，简述已经生成即可。用户明确索要展示版时再提供对应入口。此规则只影响命名与合册，不改变模型真实性、预览审批及未确认尺寸的处理方式。
