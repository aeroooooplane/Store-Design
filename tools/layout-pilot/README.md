# 已审核标注到布局试点

本工具暂停识别训练与调参，复用审核记录，将固定条件、原图参考布局和自动候选分别保存。它调用现有本机排布 API，不训练模型，不修改原图标注，不自动重设计硬装。

运行：

```sh
node --test tools/layout-pilot/core.test.mjs
node tools/layout-pilot/build.mjs <配置.json>
```

配置字段：`ids`（20–30家开发样本编号）、`acceptanceIndex`（45家身份索引）、`developmentIndex`（48家身份索引）、`bundle`（已审核整店包目录）、`out`（不存在的新输出目录）、`api`（仅本机 `/api/v1` 地址）。输出目录必须在仓库及共享资源库之外。原包须含 `构建数据.json`、`annotations/` 和 `images/`。

先校验编号、别名、同店键、源PDF哈希隔离，再冻结名单，最后读取选中标注和生成候选。24家开发子集不是训练集或独立验收集。失败不换店，所有候选包括空结果和检查提示均写入 `试点数据.json`。

产物：

- `选样与隔离.json`：名单、用途、身份索引指纹。
- `原标注/<编号>.json`：原字节副本；原审核、答案及像素坐标不改。
- `原标注/<编号>-派生记录.json`：米制几何、固定/暂留避让区、已知高度参考道具、转换轨迹、未知项、生成结果和耗时。
- `工作台项目/<编号>.store-design.json`：原生项目；空间、部分原图参考、非空且无硬错误的自动候选分开为节点。工作台首页“导入项目”即可载入。
- `审核页.html`：原图标注与各自动候选切换；集中答复、撤销、审核人记忆、保存后下一家、答复导出/同批回导。

层高3米只沿用既定H3预览默认值，非实测。未知家具高度不填；原图参考节点只含可表达的已知高度矩形家具，完整对象仍在原标注和审核页。屏幕/灯箱不转成嵌墙实体。隔断/包板保留为现状避让区而非认定不可改结构；中岛原通行路径属于设计结果参照，试点按开放场地排布。边厅通行端点只有距边界不超过250毫米才生成有记录的投影，超过20毫米必须列审核问题，原线不变。

跨界障碍仅取与门店范围的相交部分；三角剖分后只合并不改变面积的相邻凸片。不改变租赁边界、原柱或包板坐标。原有柱/原墙计入结构扣除，后场/现状设计投影仅避让；原记录与转换规则始终可查。

现有排布器仅覆盖中岛桌、收银和配件柜/边柜，数量按现有策略计算，并非原图数量硬要求。放宽间距等提示必须保留。几何通过不能代替设计业务审核；同店不同策略可能生成相同布局。

审核答复仅为新一轮补充，不覆盖旧审核，也不会自动改变训练准入。下一步根据经营需求确定必配角色及数量、完善缺失模型/高度，重新生成并记录修正工时；之后再选择与45/48隔离的数据建设训练集。
